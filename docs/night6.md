## 2. 作るもの

### ① 敵将の顔画像（`public/enemies/`）
- 80枚（王国・帝国・同盟・盗賊団 各20）。ファイル名 `{陣営}_{性別}_{年代}_{番号}.webp`、一覧は `index.json`
- 敵将を作るとき、陣営（軍なら所属国、盗賊なら bandit）に合う顔を割り当てて保存（因縁の敵将・名簿の敵将は顔を固定）。今いる敵将どうしで同じ顔にならないように。性別・年代も敵将に持たせ、名前・口上の言い回しと合わせる
- 魔物の群れの頭は今まで通り（兵種のアイコンか似顔絵）
- **卒業生が敵として現れるときは、生徒のときの顔のまま**
- 表示：出撃前の敵の情報、場面の口上、結果、年鑑、名簿。小さい表示では顔のあたりを拡大（生徒と同じ考え方）
- **傷を負って戻った敵将**は、同じ画像の上に傷跡・包帯・眼帯などを重ねて表す（SVGを重ねる。回数に応じて増える）
- 5夜目までの因縁の敵将（似顔絵）にも、変換時に陣営に合う顔を割り当てる

### ② 宿敵の仕組み 1：敵将の名簿と勢力図
- 三国の軍と盗賊団それぞれに幹部の名簿（頭目／幹部／隊長などの階級。陣営ごとに5〜8人ほど）。ゲーム開始時に作り、足りなくなれば自動で補う
- 戦況タブか年鑑に「敵将の名簿」。会ったことのない敵将は名前と顔だけ（あるいは「？」）、会うほど情報が増える（発見）
- 上の者が倒れる・引退すると、下の者が昇格。勢力の中で権力争い（新しい頭目の性格で、その陣営の依頼や口上・戦況の動きが少し変わる）
- 依頼の敵将は、この名簿から選ばれる（依頼の大きさで階級が変わる：盗賊退治＝隊長、砦の攻略＝幹部 など）

### ③ 宿敵の仕組み 2：敵将が覚えている
- 生徒を倒した（戦死・重傷）敵将は**昇進し、二つ名がつく**（「○○殺しのヴォルグ」など。二つ名は倒した相手・戦い方・性格から組み立てる）
- 逃げた敵将は**傷を負って戻る**（口上で触れる、能力が少し変わる、①の重ね絵）
- 負けた相手の生徒に執着し、次の戦いでその子を狙う（場面と判断に反映）
- 口上で過去の出来事（いつ・誰と・どうなったか）に触れる

### ④ 宿敵の仕組み 3：生徒側の因縁
- 仲間（支援の深い子・恋人）を殺された・重傷にされた子は、その敵将に**仇討ちの誓い**（その敵将との戦いで能力・やる気が上がる）
- 何度も戦った生徒と敵将は**宿敵**になり、支援のように段階で深まる（例：因縁→宿敵→生涯の宿敵）
- **決着の場面**は二人だけの特別な場面（説得・一騎打ち・討ち取る・見逃すから選べる）
- 個人ページに「宿敵」の欄（顔・二つ名・戦った回数・結果）

### ⑤ 宿敵の仕組み 4・5：弱点と、卒業生の宿敵
- 敵将に隠れた特徴（炎に弱い／弓を恐れる／一騎打ちを断れない／夜に強い／仲間を見捨てない／雨を嫌う…10種以上）。最初は「？」で、戦い・偵察（出撃前に一手使う、または斥候系の兵種がいると判明しやすい）・卒業生からの手紙で少しずつ分かる。分かった弱点を作戦・判断で突くと有利（「この戦いで分かったこと」にも出す）
- **卒業生がネメシスになる**：敵国に就職した教え子が出世し、宿敵として何度も立ちはだかる。在学中の思い出（支援・面談・卒業式の一言）を口上で語る。今ある「卒業生が戦場に現れる」「説得」とつなぐ
- 年鑑と新聞に、敵将の昇進・二つ名・因縁の決着を記録
- 仕組みをそのまま真似せず、「教え子と敵将の因縁」というこのゲームなりの形に（feedback の注記どおり）

### ⑥ 持ち越しの感想
- **疲労**：授業でたまる疲労を 8 → 7（`balance.ts` の `fatigue.lesson`）
- **名簿の一覧（簡易）を手帳のような見た目に**（罫線・紙の質感・国の色の小さな印。載せる項目は変えない）
- **手応えを広げる**：教官の腕前が上がる、卒業生の昇進・兵種昇格（新聞・手紙から個人ページを開いたとき）、施設を直す、評判が上がる、にもゲージ・「ランクアップ！」などの短い演出（タップで早送り）
- **発見を広げる**：隠れた才能のヒント1→ヒント2→判明を段階的な演出に（判明時は似顔絵＋才能の名前を大きく）。性格や夢の「意外な一面」が会話・面談で見える出来事を数種。個人ページで、まだ見えていない項目が「？」として残り、埋まっていくのが分かるように
