## 2. 作るもの

### ① 兵種を確定の木に差し替える
- `src/data/classes.ts` を `docs/new/classes.md` に合わせる：
  - 名前、もとの兵種、武器の種類、攻撃の種類、動き、飛ぶか、特技
  - 19夜目で仮だった最上級13（魔法・癒し・密偵・騎兵）を差し替える
  - 隠れた兵種は**隻眼の射手・呪いの子の2つだけ**にする（ほかの仮の隠れた兵種ははずす）
- 最上級は、それぞれの**なる条件の出来事**を、卒業生の出来事（大きな戦・宿敵戦・領主・救出など）とつなげる。条件を満たした卒業生だけがなれる。条件と、だれがなったかを年鑑と新聞に載せる
- **特技の効き目**：19夜目で「説明だけ」だったもの（無明・不動・城崩し・奇跡・蹂躙 など）も含め、`classes.md` の特技を、戦いの中でできるだけ効くようにする。むずかしいものは説明だけにして、報告書に一覧を書く
- 兵種の図鑑（どこかの画面から見られる木）：4段階の枝分かれが分かるように。なったことのある兵種は明るく、まだのものは名前だけ、最上級の条件は「？」から少しずつ明かす

### ② 先生の兵種
- `classes.md` の「先生の兵種」の案で作る：教官 → 指揮官 → 軍師 → 名将（年数と、勝った宿敵戦の数で上がる）
- 段階で号令の回数・見極めの深さが増える
- 教え子が次の先生になると、その子の兵種を持ったまま、この系統にも入る

### ③ 19夜目の「目標とくらべて」の次の手（数字の調整）
- 最初のエンディング：「最初の戦争は17年目より前には終わらない」を**21年目**に。和平の円卓と停戦の条件を少し重くする（目標：どの方針でも20〜30年目）
- 先生の代替わり：宿敵戦でさらわれる見込みを下げ、引退を60歳前後に（目標：最初のエンディングまでに、たいてい1回）
- 敵に回る教え子：故郷へ帰った子・傭兵になった子も、宿敵の陣に加わることがあるように（目標：1学年に1人くらい）
- 教え子の死：1年に0.4〜0.6人は多すぎる。おまかせが深手の子を下げるように直し、命の危険の決まりを少ししぼる（目標：40年で5〜10人ほど）

### ④ 19夜目の「未完成」を拾う（できるところまで）
- 宿敵が味方になる・好敵手・恋や友情（問12）：まずは「味方になる」（恩返し・国に裏切られた）と「好敵手」（たがいに名を呼び合い、決着を約束する）
- 密偵を送る（問17）：月に1回、宿敵ひとりに密偵を送れる。弱点・性格・次の動きが分かる。見つかると捕らわれる
- タップ対象が44pxより小さいところ（地図の上の小さな地域の札・タイトルの一部のボタン）を直す
