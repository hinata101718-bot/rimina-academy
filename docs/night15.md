# 実装指示書：15夜目（片づけ）

対象：Claude Code（クラウド、無人で作業）
依頼者：ヒナタさん（作業中はテストプレイをしています。返事はできません）

## 0. いちばん大事なこと
1. **質問で止まらないこと。** 迷ったら `docs/feedback.md` → `docs/design.md` → `docs/hearing.md` の順に意図を読み、判断して進め、判断を報告書に書く。
2. **今回は新しい機能を足さない。** 減らす・まとめる・短くする回。物差し：毎日・毎月の遊びのタップとスクロールが減ること。手応えと発見は減らさない。
3. **①〜④をすべて終えるまで作業を続けること。**
4. 段階ごとに `npm test` と `npm run build` を通してコミット・プッシュ。途中の公開でゲームが止まらないこと。
5. **既存のセーブデータを壊さない。** 14夜目版（形式14）のセーブのテストを足す。たまっている書状の未読は、まとめて読んだことにしてよい（大事な知らせだけ残す）。
6. **シミュレーション**：見た目と流れが中心なので短いシミュレーション（10年×3回）。道具の自動補充と「声をかける」のおまかせはお金と育ちに少し効くので、小さなものさし（20年×4回×方針2つ）で `docs/sim-baseline.json`（14夜目）から大きく外れないこと。
7. iPhone の Safari で確かめられないもの（タップの感じ・保存など）は、何を直して、なぜそれでよいかを報告書に。画面の絵を読み取って計算するしくみは使わない。
8. 言葉は `docs/writing-style.md`、見た目は「教官の机 × 軍記もの」。

## 2. 作るもの
### ① まず直したい5つ
- 書状のまとめと未読の数、教官手帳のやること一覧を1つに、出撃前の「おすすめで出撃する」と、たたむ欄、授業の画面の説明と体力、設定の片づけ
### ② 要らないかもしれない機能
- 「声をかける」のおまかせ、道具の自動補充、戦況タブの重なり、年鑑の新聞タブ、個人ページの重なりと古い文
### ③ そのほかの不便
- 入口の整理と図鑑を1か所に、長い画面を短く、兵種試験を2タップに
### ④ 仕上げ
- 1か月の操作の数（授業の20日と月末の1部隊・3部隊）を14夜目と比べて報告書に。はみ出し・横ずれの確認（幅360・390・430）。撮影は最後にまとめて1回（`docs/screenshots/night15/`）
