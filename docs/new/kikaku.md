# 企画書：辺境士官学校 ―戦争が終わる日まで―（宿敵の仕組みでブラッシュアップ）

2026-11-09　ヒアリング（`docs/new/hearing.md` 問1〜問77）をもとにまとめたもの。
「問○」は、ヒアリングの記録の番号です。細かい数値や名前は、Claudeが決めて書いています（★の印）。

## 0. ひとことで言うと

**どの国にも属さない辺境の士官学校で、教え子を育てて戦場へ送り出す。戦場で出会った敵の将は、教え子ひとりひとりの名前と、受けた傷を覚えていて、強くなって、また現れる。**
先生が年をとれば、教え子の中から次の先生が生まれる。何十年も続く因縁の果てに、戦争が終わる日を目指す。

### いちばん味わいたい瞬間（第1回・全部）
- 宿敵と再会して、ゾクッとする
- 教え子が、宿敵を討つ
- 自分の選んだことで、世界が動く
- 死や裏切りの重さ
- 死んだと思っていた敵が、生きていた

## 2. 世界

- **雰囲気**：王道の西洋ファンタジー。剣と魔法。明るさと重さが半々（問5）
- **国**：三つの大国と、小さな勢力（小国・自由都市・山の部族・盗賊団など）（問6）
- **学校**：どの国にも属さない。三国すべてから生徒が来て、卒業後はそれぞれの故郷へ帰る（問4）
- **始まり**：長い平和が崩れかけている。在学中に因縁が生まれ、卒業のころに本格的な戦争になる（問7）
- **終わり**：戦争が終わるとエンディング。そのあとも「この学校を続ける」で遊べる。大宿敵との決着が山場（問8）
- **最初のエンディングまで**：ゲームの中で20〜30年。たいていは、先生が1回代替わりする（問55）。和平の大成功などで早く終わる道は、まれな結末として残す
- **大きく負けても**：バッドエンドはなし。学校を焼かれる・先生がさらわれる、などの大きな痛手のあと、残った教え子と立て直す（問56）

## 3. 宿敵（ネメシス）の仕組み ― このゲームの主役

### 3.1 人数と生まれ
- 三国と小さな勢力を合わせて、**名前のある将が40〜60人**。そのうち学校と因縁を持つのは、**いつも10人前後**（問13）
- 宿敵の生まれ（問14、敵の学校の生徒は取り消し）：
  - 戦場で目立った雑兵が、抜擢されて将になる
  - 敵に回った教え子
  - 過去の人物（先代の先生・先代の宿敵・昔の戦の生き残り）
  - 生まれつきの縁（教え子の血縁など）
- 最初の宿敵は、ゲームの始まりの戦いで生まれる（問73）

### 3.2 覚えていること（問9・全部）
1. **だれに負けたか・傷つけられたか**：教え子を名前で覚える
2. **戦い方**：やられた作戦や技に、対策してくる
3. **恩**：手心を加えられた・助けられた。助けに来たり、のちに味方になったりする
4. **屈辱**
5. **大切な人を奪われたこと**：仇として執着する。恨みは代を越えて続く

### 3.3 再会までに変わること（問10・全部）
- 強くなる
- 体に傷跡が残る
- 地位が上がる
- 心が変わる（慎重になる・狂う・丸くなる）
- 仲間を集め、軍を率いる
- 落ちぶれても、執念で追ってくる

### 3.4 二つ名（問67・問68）
- 宿敵は、最初は名前と肩書きだけ。生徒を倒した・片目を失った・蘇った、などの出来事で、「隻眼の〜」「三度目の〜」のような二つ名がついたり変わったりする。言葉の組み合わせで作る★
- 生徒にも、在学中から二つ名がつく。ただし、宿敵を退けた・仲間をかばって大けがをした、などの大きな出来事のときだけ

### 3.5 死んだと思った者が生きていた（問11）
- **とどめを刺しても、まれに生きている**：名前のある敵だけ。影武者だった・癒し手に救われた・死体が見つからなかった、などの理由つき。**一度蘇った者は、次に討てば本当に死ぬ**。逃がした・崖から落ちた、などのときは、もっと戻ってきやすい
- **魔法や呪いで蘇る**：たまに起きる大事件。姿や名前が少し変わる
- **味方にも起きる**：戦死したと思った教え子が、捕らわれて生きていた

### 3.6 関係の変わり方（問12・全部）
いつまでも敵／好敵手／味方になる／恋や友情／味方が敵になる

### 3.7 敵の組織の中で起きること（問16・全部）
昇進と降格、権力争い（暗殺・失脚）、派閥（宿敵どうしが組むことも）、抜擢、処刑・追放（落ちぶれ・寝返り）、代替わり（子や弟子が継ぐ。親の仇を討とうとする二代目）

- こちらからの手出しは、**密偵だけ**（弱点・性格・次の動きを探る。見つかると捕らわれる）。大きな要素にはしない（問17）

### 3.8 情報の見え方と再会（問18・問19）
- はじめは顔と名前だけ。戦うたび、密偵の報告があるたびに、性格・得意な戦い方・弱点・恨みの中身が埋まっていく
- 再会の起き方は、場面で使い分ける：
  - 戦いの前に知らされる
  - 戦いの最中に突然現れる（復活はここで起きる）
  - うわさで先に知る
  - 戦場の外で会う（和平の席・捕虜の引き渡しなど）

### 3.9 宿敵が言葉を発する場面（問54・全部）
- 戦いの前の口上
- 戦いの中：盾を割られた／ブレイクした／追いつめられた／教え子を倒した
- 戦いのあと：捨て台詞／最期の言葉／勝ったとき
- 手紙：果たし状・恨み言・礼状
- 新聞やうわさの中
- 教え子の名前を呼ぶ言葉

### 3.10 因縁の長さ（問64）
まちまち。すぐ決着する宿敵もいれば、何十年も続く大宿敵もいる。多くは5〜10年★

### 3.11 見た目（問53・問76）
- 札の飾り（枠・色・二つ名の帯・ひび）
- 再会のとき、「前に会ったときの札」と「今の札」を並べる
- 変化を文で語る（「左目に黒い眼帯。あのときの傷だ」）
- 札に「傷」の欄
- 顔の絵：今ある顔（生徒用約110・敵用約80）を使う。**顔の絵には傷などを重ねない**（絵の質がそろわないため）。同じ時期に同じ顔の人物は出さない（問76・確認で問53に統一）
- 思い入れのある宿敵だけ、あとから顔を描き足す

### 3.12 因縁の帳（問58）
- ホームの机に置く「因縁の帳」が中心。のせるもの：顔・二つ名・体の傷・覚えていること・教え子との因縁・最後に会った日
- 教え子の個人ページの関係タブ、組織図の印、勢力図の領地の顔からも、同じ札にたどり着く

## 4. 学校と生徒

### 4.1 人数と入学
- 3年制。1学年6〜8人、全体で20人前後（問21）
- **始めたとき**：1年生6〜8人と、頼れる上級生2〜3人。上級生は1〜2年で卒業する（問74）
- **新入生**：毎年10人ほどの希望者から、6〜8人を選ぶ。学校の評判で希望者が変わる（問75）
  - 評判が上がると、才能のある子・遠い国の子が来る
  - 宿敵に家族を奪われた、仇討ちの子が来ることもある

### 4.2 能力（問22）
| 種類 | 中身 |
|---|---|
| 体の7つ | 体力・力・魔力・技・速さ・守り・魔防（魔力もだれでも伸びる。守り＝武器の攻撃、魔防＝炎・雷・氷・光・闇）（11/10 魔防を追加） |
| 人望 | 能力ではなく、平静・先生への信頼・家柄・二つ名から出す。文官・和平・出世・声かけに効く（11/10 問113） |
| 心の3つ | **闘志**（燃えると強い／高すぎると無茶をする）・**平静**（恐れや怒りに飲まれない）・**執念**（仇の前で力が出る） |
| 教訓 | 戦いの経験から身につく力。「騎兵に強い（ザラに二度負けた）」のように、出来事つきで残る |
| 全盛期と衰え | 若いうちは伸び、年をとると衰える（宿敵も同じ） |

- 伸び方：授業で少しずつ伸び、レベルアップで大きく伸びる。宿敵との戦い・仲間の死などの大きな出来事で、心と教訓が大きく動く（問23）

### 4.3 個性（問24・全部）
- 入学のときに分かるもの：性格・出身の国と家柄・夢
- 少しずつ明らかになるもの：秘密・才能の芽（一部の子だけ）・生まれつきの縁

### 4.4 関係（問25・全部）
友情、恋（告白・両想いまで）、ライバル、先輩と後輩、不仲（裏切りの種）、師弟

### 4.5 1週の過ごし方（問50・問51・問72）
- 週のはじめに、**授業の札を1枚と、交流の札を1枚**選ぶ
- 1か月に4回選び、月末に出撃する
- 同じ選び方を続けるときは、「先週と同じ」ボタン1つで進む
- 1年の長さは30分が目安。超えてもよい
- 宿敵に向けた授業（問61）：
  - 弱点の研究：その弱点を突ける技を覚えやすくする
  - 心の鍛錬：平静を上げる・燃えすぎた執念を鎮める
- 交流の中の宿敵の場面（問62・全部）：
  - 秘密や縁が明らかになる
  - 執念の燃えすぎた子の暴走を止める
  - 裏切りの兆しに気づく
  - 敵国の友とのつながりを知る
  - 仇を討った子の空しさを支える

### 4.6 卒業と、その後（問26・問27・問63）
- **進路**：先生が勧め、生徒が決める。勧めを振り切って、敵国へ帰る子もいる
- **敵に回る教え子**：育て方しだい（信頼・進路の勧め・故郷の事情）。1学年に1人くらい
- **卒業生とのつながり（全部）**：
  - 組織図に入る
  - 手紙が届く
  - 卒業後も育ち、出世する
  - 援軍として戻る・次の先生の候補になる
  - 戦場で、味方としても敵としても出会う
  - 家族を持ち、その子が入学してくる

## 5. 先生と代替わり（問2・問3・問57）

- **最初の先生**：ふつうの教官
- **代替わり**：次の先生は、教え子の中から選ぶ。その子が抱えている因縁を、そのまま持って先生になる
- **代替わりのきっかけ**：
  - 年をとって引退
  - 戦場で倒れる・さらわれる（何年もあとに敵として現れることも）
  - 先代が敵に回る
  - 自分で好きなときに譲ることはできない
- **戦場での先生**：
  - 指揮をとる人。「号令」で仲間をもう一度動かす、「見極め」で隠れた弱点を明かす。攻撃は弱め
  - 守られる人。先生が倒れると、その戦いは負けで、さらわれる危険もある。宿敵が先生を狙ってくることもある

## 6. 戦い

### 6.1 形（問32・試作「宿敵戦の試作」が土台）
- 小さなマス目の戦い（6×8くらい★）
- **運はなし**。攻撃は必ず当たり、ダメージは決まった計算
- 敵の次の狙いが見える
- **盾と弱点**：
  - 攻撃には種類がある（斬・突・射・炎・光など）
  - 弱点を突くと、盾が1つ割れる
  - 盾が0になると**ブレイク**：次の番は動けず、受ける傷が2倍（問37。ほかの効果はなし）
  - ブレイクの瞬間は、カットインと乱れ斬り
- 宿敵の手強さ：
  - 執念で一度だけ持ちこたえる
  - 追いつめられると逃げる
  - 前に割られた弱点が効かなくなる
  - 前に自分をやった教え子を真っ先に狙う（問42）

### 6.2 操作（問36）
1. 教え子をタップすると、動ける範囲（青）と、そこから攻撃できる敵（赤）が一度に光る
2. 赤い敵をタップすると、いちばんいい場所へ自動で動き、技の札が並ぶ
3. 札には、ダメージ・盾が割れるか・弱点かが出ている
4. 札をタップして実行する

- 動くだけのときは、青いマスをタップする
- 「ひとつ戻す」ボタンがある

### 6.3 技（問38・問39）
- 育つほど技が増える。技ごとに攻撃の種類が違い、いろいろな弱点を突けるようになる
- 1回の戦いで使える回数が決まっている（「燕返し　のこり2」）

### 6.4 出撃（問40・問41）
- 教え子4人と先生
- ふつうの戦いでは、交代で全員が出る
- 宿敵戦には、その宿敵と因縁のある子が必ず入る
- 出撃しない子は、後ろで支える。薬を作る・罠を仕掛ける・弱点を調べる。その成果が戦いの中に出る
- 毎月のふつうの戦いは、自分で遊ぶか「おまかせ」で結果だけ見るか選べる。おまかせでも名場面は残る

### 6.5 戦場と勝ち方（問43・問44）
- 地形は基本だけ（森で守りが上がる・岩は通れない）。それに加えて、宿敵ごとの戦場がある（ザラは自分の砦、など）
- 勝ち方：
  - 敵将を倒す（討ち取る・退ける）
  - 全員倒す
  - 守り抜く
  - 救い出す
  - 逃げきる
- 宿敵を討つか逃がすかは、戦いの流れで自動で決まる（問20）

### 6.6 宿敵戦のきっかけ（問52）
- 依頼の先に宿敵がいる（受けるか選べる）
- 宿敵から挑んでくる（断れないこともある）
- 執念の燃えた教え子が、許しを待たずに向かってしまい、追いかけて助けに行く

### 6.7 死（問45・問69）
- 教え子が死ぬのは、決まった危ない場面だけ（宿敵のとどめ・ブレイク中の一撃など）
- 危ない攻撃には、前もって「命の危険」のしるしが出る。読めば避けられる
- 「生徒が死なない」設定では、死ぬ代わりに大けがで済む。傷跡は残る

### 6.8 見た目（問46）
- 顔の札のマス目のまま、斬撃・揺れ・数字・カットインを派手にする
- 攻撃のたびに、1対1の場面を見せる（攻める子と受ける子の顔が大きく向かい合う）
- この場面は、設定で短く・切ることもできる

---

### 6.9 進軍（11/10 問114〜118）
- 1回の依頼で戦場を1〜5つ続けて攻め込む。盤は8×10、出撃は教え子6人＋先生、敵は1つの戦場に8〜12人
- 戦場のあいだ：体力と技の回数は持ち越し・小休止を1つ・道を選ぶ・追いつめた宿敵は次の戦場へ逃げて待ち構える
- 国どうしの大きな戦には、学校は加わらない

## 7. 勢力図（問47〜問49）

- **学校が勢力図を動かす方法**：
  - どの国の依頼を受けるか。受けた国が有利になり、断った国の評判は下がる
  - 学校の評判。評判が高いと、仲立ちや和平の席につながる
- **勢力図を「人の地図」にする**：
  - 領地に、治める人・守る人の顔
  - 宿敵が領地を奪って治める
  - 教え子も領主になる
  - 大きな戦の勝ち負けは、将の力で決まる
  - 教え子と宿敵が、国境をはさんで隣り合う
- **動く速さ**：ふだんはゆっくり（1年に数か所）。大きな戦争の年だけ大きく動く

## 8. 画面・音・遊びやすさ

- **雰囲気**：「教官の机 × 軍記もの」のまま。平和な時期・春夏は昼の光、戦争の時期・冬は夜のろうそく（問59）
- **音**：効果音だけ（弱点を突く・盾が割れる・宿敵が現れる、など）。ゲームの中で音を作り、設定で切れる。音楽は後のアップデートで（問66）
- **難しさ**：「やさしい・ふつう・きびしい」から選ぶ。別に、「生徒が死なない」設定もある（問69）
- **セーブ**：自動セーブと、手動の記録枠3つ（問70）
- **タイトル**：今のまま（問65）

## 9. 始まりの流れ（問73・最初の1時間★）

1. 着任の道中で、敵の部隊に襲われる。生徒を守って戦う。**この戦いが、戦い方の説明も兼ねる**。その敵将が、最初の宿敵になる（逃げられることもある）
2. 学校に着く。上級生と1年生に出会う
3. 最初の1か月：授業と交流を4週。因縁の帳の使い方を知る
4. 最初の月末の出撃：ふつうの戦い。おまかせも選べることを知る
5. 2〜3か月目：最初の宿敵のうわさが新聞に出る。再会につながる

| **20夜** | **新しい戦い（土台）**：マス目・運なし・盾と弱点・ブレイク・直接タップの操作・ひとつ戻す・技の残り回数・カットイン | 試作より押しやすいか |
