# 兵種の木（確定）

2026-11-10　**確定**。ヒアリング 問78〜問111（`docs/new/hearing.md`）で、ヒナタさんが1つずつ選んで決めたもの。
特技の中身・なる条件のうち、ヒナタさんが名前だけを決めたものは、Claudeの案を当てている（★）。

## 決まり
- **4段階**：初級（入学）→ 中級（1年目の終わり）→ 上級（3年目）→ 最上級（卒業後、条件の出来事を成し遂げた子だけ）
- **つながり**：枝分かれの木（＝おすすめの道。試験は条件しだいでほかの枝へも）（初級から2〜4つに分かれる）。最上級は上級ごとに1つ。ほかに、出来事で道が開く隠れた兵種が2つ
- **上がる条件**：授業で技能を上げる＋出撃の回数（軽め。宿敵戦は早く満たせる）＋決まった日の試験
- **試験の受け方（11/10 変更）**：次の段階の兵種のうち、**技能の条件を満たしているものなら、枝分かれの先でなくても受けられる**（風花雪月のように）。試験の候補には**条件を満たしているものだけ**を並べる。下の枝分かれは「おすすめの道」として図鑑に残す。最上級は出来事の条件も要る。隠れた兵種は出来事で開く
- **行き先**：先生が勧め、生徒が決める（信頼が高いほど勧めを聞く。性格・夢・執念で違う道を選ぶ子も）
- **兵種で変わるもの**：動き方・攻撃の種類・覚える技・能力の伸び・兵種だけの特技・使える武器（種類で縛る）・札の見た目
- **特技**：下の段階の特技は、上がっても残る
- **攻撃の種類**：斬・突・射・砕・打・炎・雷・氷・光・闇
- **数**：初級8＋中級24＋上級26＋最上級26＋隠れた2＝**86**

## 先生の兵種（Claudeの案・ヒアリングでは聞いていない）
- 先生だけの系統：**教官 → 指揮官 → 軍師 → 名将**（年数と、勝った宿敵戦の数で上がる）
- 攻撃は弱く、特技で戦う：**号令**（仲間をもう一度動かす）・**見極め**（隠れた弱点を明かす）。段階が上がると、号令の回数と見極めの深さが増える
- 教え子が次の先生になると、その子の兵種を持ったまま、この系統にも入る（剣神の教官、など）
