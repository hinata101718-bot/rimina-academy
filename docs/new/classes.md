# 兵種の木（たたき台）

2026-11-10　ヒアリング 問78〜問87 をもとに、Claudeが作ったたたき台。ヒナタさんの直しを待つ。

## 決まっていること
- **4段階**：初級（入学）→ 中級（1年目の終わり）→ 上級（3年目）→ 最上級（卒業後、宿敵を討つ・大きな戦で名を上げた子だけ）
- **枝分かれの木と横道**：ふだんは木。教訓・宿敵・出来事で、隠れた兵種への道が開く
- **上がる条件**：技能（授業）＋出撃の回数＋試験
- **行き先**：先生が勧めて、生徒が決める
- **兵種で変わるもの**：動き方・攻撃の種類・覚える技・能力の伸び・兵種だけの特技・使える武器（種類で）・札の見た目
- **名前**：兵種ごとに合う書き方（漢字もカタカナも）
- **数**：先に決めない。ひとつひとつ、戦い方か役目がはっきり違うこと

**攻撃の種類**（弱点になるもの）：斬・突・射・砕・打・炎・雷・氷・光・闇

## 最上級（8）：卒業後、名を上げた子だけ。系統ごとに1つ
| 系統 | 兵種 | なる条件の例 | 特技 |
|---|---|---|---|
| 剣 | 剣聖 | 宿敵を一騎打ちで討つ | **無明**：一度だけ、どんな盾も割る一閃 |
| 槍 | 槍聖 | 守り抜く戦で将を退ける | **不動**：その場から動かない番、だれも隣を抜けない |
| 斧 | 破城 | 砦攻めで城門を落とす | **城崩し**：宿敵の戦場の壁や門を壊す |
| 弓 | 弓聖 | 逃げる宿敵を射止める | **千里の矢**：盤のどこへでも届く |

| 騎兵 | 覇騎 | 大きな戦で、軍を率いて勝つ | **蹂躙**：まっすぐ駆け抜けた線の敵すべてに当てる |

## 隠れた兵種（10）：出来事で横道が開く
どの段階からでも、条件を満たすと、勧めの中に「？」として出てくる。

| 兵種 | 開く出来事 | 特技 |
|---|---|---|
| 隻眼の射手 | 宿敵に片目を奪われる（弓・密偵の系統） | 遠くは苦手、2マス先への射が必ず盾を割る |
| 仇討ち | 宿敵に家族や親友を奪われ、執念が最高に | その宿敵との戦いでだけ、すべての能力が上がる |
| 死に損ない | 「命の危険」の一撃から2度生き延びる | 体力0になっても、1度だけ立ち上がる（宿敵の執念と同じ） |
| 宿敵狩り | 宿敵を3人討つ | 宿敵の盾を、最初から1つ少なくする |
| 盾の誓い | 仲間をかばって大けがを3度負う | かばった仲間は、その戦いで倒れない |
| 無刃 | 武器が壊れたまま戦いに勝つ | 武器を持たない。打の技が強く、盾を割りやすい |
| 呪いの子 | 呪いで蘇った（味方） | 闇を使える。光に弱い。蘇りの記憶を語る |
| 双星 | 両想いの2人が、同じ宿敵戦で活躍する | 隣にいると、2人で1つの技を放つ |
| 背信の剣 | 敵に回った元教え子（敵だけ） | 学校で習った技をすべて使い、先生の癖を知っている |
| 語り部 | 卒業後、講師として学校に戻る | 後ろから、教え子の心（平静・闘志）を整える |

## 先生の兵種（別）
- 先生だけの系統：**教官 → 指揮官 → 軍師 → 名将**
- 攻撃は弱く、特技で戦う：**号令**（仲間をもう一度動かす）・**見極め**（隠れた弱点を明かす）。段階が上がると、号令の回数と見極めの深さが増える
- 教え子が次の先生になると、その子の兵種を持ったまま、この系統に入る（剣聖の教官、など）
