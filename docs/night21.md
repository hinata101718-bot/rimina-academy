## 2. 作るもの

### ① 特技の残り
- **入れ替え（問112）**：トリックスターをタップすると、青（動ける）・赤（攻撃できる敵）に加えて、入れ替えられる仲間が**紫**に光る。紫をタップすると場所を入れ替える（その番の行動になる）。**道化王は敵も紫に光り**、敵どうしの場所も入れ替えられる（敵を1人タップ → 入れ替え先の敵が紫に → タップ）。届く距離は★Claudeが決める（目安：トリックスター3マス、道化王4マス）。「ひとつ戻す」でもどせること。おまかせも、命の危険のしるしがついた仲間を逃がすのに使う
- **2手先の狙い（千里眼・天眼）**：敵の次の狙いの矢印に加えて、その次の狙いを薄い色で見せる
- **宝箱と扉（盗賊）**：盤にときどき宝箱（武器や薬）と扉。盗賊の系統だけ開けられる
- **火をつける（火矢兵）**：森のマスに火矢を当てると燃える（数ターン、通る者が傷を負う）。宿敵の砦の木の門にも
- **呪いの子の記憶**：交流の場面で、蘇ったときの記憶を語る会話を2〜3種

### ② 宿敵との恋や友情（問12の残り）
- 宿敵（敵国の将）と教え子のあいだに、**友情**と**恋**が芽生えることがある：戦場の外の再会（捕虜の引き渡し・和平の席）、恩、好敵手の約束から
- 芽生えると：交流の場面（手紙・思い出話）、宿敵戦の口上が変わる、とどめを刺すか迷う場面、宿敵が味方になる見込みが上がる、どちらかが討たれたときの重い場面
- 恋は告白・両想いの気持ちまで。多すぎないこと（目安：40年で数組）

### ③ 数字の直し（20夜目の「次の手」）
- **先生の代替わり**：はじめの先生の年を35〜42歳に上げ、57歳ごろに「引退を考える」場面を出す（目標：最初のエンディングまでに、たいてい1回）
- **敵に回る教え子**：国ごとの「卒業生の敵将」の上限を4→6人に、卒業後の年を4→8年に（目標：1学年に1人くらい）
- **最初のエンディング**：和平の円卓と停戦の条件をもう一段重く（目標：22〜28年目に散らばる）
- **戦死**：おまかせは、宿敵戦で深手の子を出撃させない（目標：40年で5〜10人）
- **最上級**：卒業後に条件の出来事を成し遂げる見込みを半分に（目安：40年で10〜30人）

### ④ 小さな直し
- 年鑑の卒業生の一覧と先生の頁で「-1期生」と出る子（最初からいる上級生の期の数え方）を直す
