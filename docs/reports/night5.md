## 遊び方と見てほしいところ

いつものURLで、**今のセーブのまま続きから遊べます**。読み込むと「戦闘が自動で決着するようになりました」というお知らせが一度出ます。戦闘の途中で保存していた場合は、その戦闘だけは今までどおり自分で指揮して続けます。

1. 月末の依頼掲示板で依頼を選ぶ → **出撃前の画面**。まず「おすすめの編成」のまま、**作戦の方針**を変えてみてください。「勝ち目の目安」が変わることがあります。
2. 「出撃する」→ 場面をタップで送ります。**ここぞの判断**で、助けに行くか・作戦を優先するか、などを選びます。急ぐときは「早送り」か「結果だけ見る」。
3. 結果の画面で **MVP** と **講評** を見てください。講評に「役割が兵種に合っていない子がいた」などが出たら、次は役割を見直すと勝ちやすくなります。
4. 取り逃がした敵将は、年鑑 →「記録」のいちばん下「因縁の敵将」に残ります。同じ国の依頼で、また口上つきで現れます（出撃前の画面に「因縁」の札）。
5. 自分で動かしたいときは、出撃前の画面の下のチェック、またはずっと手動なら「設定」→「戦闘を自分で指揮する」。

見てほしいのは、(1) 1戦闘の長さ（1〜2分に収まっているか）、(2) 場面の文が単調に感じないか、(3) 判断の数（1〜2回）がちょうどよいか、(4) 自動の戦闘で、育てた子の活躍が感じられるか、です。
