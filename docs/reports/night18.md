# 18夜目の報告

今回は「**技の夜**」です。途中で足された **⓪（札が重なる・案内が出ない）** をいちばん先に直して公開し、そのあと ①〜⑤ を**すべて作り終えました**。今のセーブのまま、いつものURLで遊べます（読みこむと「18夜目の新しいこと」が出ます）。

## 見てほしいところ（3つ）

1. **札を出す画面の手札**（`docs/screenshots/night18/hand/w390-hand5.png` ほか）：手札は**いつも1行**に並び、札の幅は画面の幅から決まります。手札とボタンは画面の下に固定し、上の敵と味方だけが動くので、**札がボタンにかぶりません**。押した札の説明は、手札のすぐ上に全部出ます。幅360・375・390・393・430 × 手札5・7・9枚で、重なり0・はみ出し0でした。
2. **連携技**（`01-combo-hand.png`〜`04-combo-result.png`・`12-talk-combo.png`）：支援がBになった2人に、2人だけの札ができます。手札に2人の札がそろうと**縁が金色**に光り、2枚を続けて選ぶと「この2枚を出す（連携技）」。出すと2人の顔が寄って合わさる演出のあと、強めた2枚が同じ敵へ続けて打ちこみます。連携技ができたときは、支援会話のあとに「発見」が出ます。
3. **技の進化**（`11-evolve-pending.png`・`07`・`08`・`05-arts.png`）：戦技と魔法は使うたびに**熟練**がたまり、満ちると**2つの進化先から1つを選びます**（例：燕返し → 「二段燕」攻め／「燕返し・守」反撃）。個人ページに熟練のゲージ、満ちた技には「進化させる」。同じ技でも育て方で、その子だけの技になります。

## 今のセーブで見る方法

- **手札と案内**：次の月末の戦いで、そのまま。案内（戦い方が新しくなりました）にまだ答えていなければ、次の戦いの最初のターンに出ます。
- **連携技**：支援がB以上の組には、もう連携技ができています（お知らせに組の数）。出撃前の「山札を見る」に、その部隊の連携技が出ます。
- **進化**：戦いのあとに熟練が満ちた技があれば、2択が出ます。「あとで選ぶ」もできます（個人ページの技能タブから）。設定の「技の進化」で「おまかせ」にすると、その子の性格に合う方を自動で選び、結果だけ見せます。

## 判断したこと

- **作業の置き場所**：指示書どおり `main` へ。作業用のブランチ（`claude/night18-work-completion-myyop3`）にも同じものを入れました（15〜17夜目と同じ）。⓪は①と一緒に、作業のいちばんはじめに公開しました（①はそのときもう出来ていて、テストも通っていたため）。
- **手札が9枚のとき**：幅360〜393では、1行に9枚並べると1枚が44pxより狭くなります。重ねると押せる幅がもっと減るので、**9枚のときだけ、手札の列の中で横に動かせる**ようにしました（1行のまま・重ならない・44px以上）。手札が9枚になるのは、10人の部隊で「札を多く引く」スキルが重なったときだけです。
- **札の全文**：「タップで全文」は、タップが札を選ぶ操作なので、かわりに**押した札の説明を手札のすぐ上の帯に全部出す**ようにしました。
- **案内**：17夜目は「案内を飛ばして始める」で札の戦いの案内も止めていましたが、感想に合わせて、**止めるのは案内のお知らせで「案内を見る／飛ばす」を押したときだけ**にしました。18夜目の版で読みこむと、まだ答えていないセーブは次の戦いで出ます（もう答えたかどうかは17夜目のセーブには残っていないので、どのセーブにも一度だけ出ます。飛ばせます）。
- **スキルの節目**：技能×節目（E+・D・C・B・A・S）のうち、E+・C・Aはスキル（2つから1つ）、D・B・Sは戦技（もとの4つに、札になるスキルを足して5〜8つから1つ）。札になるスキルは、もとの節目から1つ後（E+→D・C→B・A→S）で覚えます。
- **1人の表に同じ効果を入れない**：好みの順に並べてから、重なったところだけ組み替える方法で選びます（600人の試しで重なり0）。古いセーブで、もう覚えたスキルどうしの組み合わせでどうしても重なる節目は、**その節目を空ける**（スキルを覚えない）ことにしました。
- **古いセーブ**：なくしたスキル34個は、同じ技能・同じ節目の新しいスキルに入れ替えました（名前が変わります。入れ替えの演出はなし）。覚えたスキルの中で同じ効果が重なっていたら、あとのほうを同じ節目の別の効果に。札になるスキルが戦技へ移って空いた節目のスキルは、読みこんだときに演出なしで覚えます。つけているスキルが4〜5つの子はおまかせで3つに、戦技と魔法が6つ以上になった子は5つに。
- **名前の重なり**：点検で、もとからあった名前の重なりが見つかったので直しました（戦技「突撃」→「馬上突撃」、「流星」→「流星の矢」、「王剣」→「王道の一太刀」、「覇気」→「覇王の気迫」、札「鉄壁」→「鉄壁の構え」、「雄叫び」→「鬨の声」、「魔力循環」→「魔力の巡り」、スキル「鷹の目」→「鷹の眼差し」、「叡智」→「魔の叡智」。12の技能で同じ名前だった開花の技「眠りからの一撃」は、「眠りからの一太刀」「眠りからの一矢」など技能ごとに）。兵種のスキルの名前はそのままです。
- **「燕返し＋」の整理**：技能のランクで強くなる「＋」はなくし、**熟練に入れました**（覚えてから技能の節目を1つ越えるごとに熟練+3）。こうすると、ランクが上がった技ほど早く進化を選べます。今のセーブで「＋」だった技は、熟練が6以上たまっているので、1〜2回使うと進化できます。
- **進化先の決め方**：すべての技に手で2つずつ書くと1500通りになるので、**札の効き目と流派（攻め・守り・速さ・搦め手・重さ・格式）から決まる**ようにし、名前は「燕返し・剛（攻め）」「燕返し・守（反撃）」「真・二段燕（極めた）」の形にしました。各技能の最初の戦技など12の技は、名前と進化先を手で書きました（`src/data/evolve.ts` の `EVO_OVERRIDE` に足すだけで増やせます）。
- **進化の知らせ**：戦いのあとにまとめて出ます。シミュレーションでは、1年に30ほど（学校全体で、1か月に2〜3回）。多すぎると感じたら、設定の「技の進化：おまかせ」にすると、結果だけの短い知らせになります。
- **連携技の「続けて出す」**：選んだ順で、連携技の2人の札が**隣り合っていれば**合わさります（間に別の札をはさむと、ふつうの2枚）。行動力は2枚分です。連携技は、攻撃の札と同じ順（守り・強めの札のあと）に打ちます。
- **連携技ができる組**：支援Bになった組は、関係の種類（ふつうの仲・恋人・好敵手・先輩と後輩）にかかわらず、すべてにできます。ふつうの仲の組は「息の合った連携技」です。
- **連携技の名前**：2人の「いまの兵種のいちばんの武器」（なければいちばん得意な技能）と性格から作ります。はじめは技能ポイントのいちばん多い技能から作っていましたが、信仰・魔道ばかりになったので変えました。
- **連携技でも信頼で言うことを聞かない**ことはありません（2人で息を合わせる技なので）。
- **敵の技**：札になるスキルが戦技に移ったので、そのままだと敵の兵・敵将が「かばう」などを戦技として持ってしまい、攻撃の戦技を使わなくなっていました。敵は**攻撃の戦技だけ**を持つようにし、17夜目までと同じ強さに戻しました（これに気づいたので、1度目の長いシミュレーションを途中で止めて、直したあとで回し直しました）。
- **テストの時刻**：17夜目の報告にあった「まれに落ちる古いテスト」（依頼の戦いの種に、ゲームを作った時刻が入るため）は、**テストの中だけ時刻を決めておく**形に直しました（`tests/setup.ts`）。ゲームそのものは変わりません。
