### ② 評判
- **わけ**：依頼に勝つたびに評判が上がり（年に約20）、下がる力（年度末に少し落ち着く・失敗・戦死）が弱かったため、5年目に100まで上がって、年度末に95へ戻る、をくり返していました。
- **直し方**（数字は `src/data/balance.ts` の `reputation`）
  - 上がり方をゆるやかに：依頼に勝ったときの評判を、危険度ごとに 1.1／1.5／2.0 → 0.8／1.1／1.5 に。
  - **高いほど上がりにくく**：評判60から上は、上がる量がだんだん細り、評判100の手前で15%まで。**95より上へは、大きな出来事（評判+3以上：学校防衛戦に勝つ・演武会の勝ち・卒業生の大きな昇進など）でしか上がりません**。
  - **下がる出来事をはっきり**：依頼の失敗 −2 → −4、教え子の戦死 −3 → −5、**卒業生が敵に回る −2（新しく）**、**依頼を断り続けた国 −2（新しく）**。年度末に落ち着く力も少し強く（0.08 → 0.13）。
  - 評判がまだ40より低い学校は、失うものも少ないので、下がり方を小さくしました（序盤に0まで落ちて動けなくならないように）。
  - 「断った国」：1年のあいだに、その国の依頼を4回以上見送り、1つも受けなかった国は、年度末に「頼りにならない学校だ」と噂して評判−2。年表にも残ります。
  - 学校の画面の評判の説明に「失敗・戦死・敵に回った卒業生で下がる」「高くなるほど上がりにくい」を足しました。
- **入学の希望者**：評判で、希望者の数（10人＋評判25ごとに1人）・遠い国の子・育ちのよい子・仇討ちの子が変わる仕組みは、そのままです。評判が95に張りつかなくなったので、12年のあいだずっと効きます。テストで、評判55と85で希望者の数・遠い国の子・育ちのよさが変わること、12年回して6年目からの評判が95より下で動き続けることを確かめています。

### ③ 兵種のかたより
- **数えた**：直す前の40年（4回）で、在籍の子の系統は魔法がいつも1番（平均19%、10年ごとに見ると33%の時期も）。密偵・騎兵・斧は7〜8%と少なめでした。
- **わけ**（調べた順）
  1. **入学のときの兵種**：いちばん育った技能で初級が決まります。夢（学者・平和・軍師）と出身国（帝国・同盟の両方）が魔法の技能を後押しするので、入学の時点で魔道士が17〜23%と多め。評判が上がると遠い国（同盟など）の子が増え、さらに魔法・癒しが増えていました。
  2. **在学中の移り**：騎兵などから、得意に合う癒し手・魔道士へ移る子が多い（おまかせの「得意に合わない初級なら移る」）。
  3. 兵種の条件（req）の重さ・魔防を足したことは、大きな原因ではありませんでした（中級・上級はほぼ同じ系統の中で上がるため）。
- **直し方**（数字は `balance.ts` の `classMix`）：先生が「隊の釣り合い」を考えるようにしました。
  - **入学のおまかせ**：学校に多い系統の子を少し後ろに回します（1人ぶん多いごとに、能力の合計で6点ぶん）。入学の画面で最初から選ばれている子も、このおまかせです。自分で選び直すのは自由です。
  - **初級どうしの移り（おまかせ）**：1年生で、その系統が学校の19%をこえていたら、得意か夢に合う、11%より少ない系統の初級へ移ります。
  - **先生の勧め（試験）**：学校に多い系統は少し点を下げ、少ない系統は少し上げます。
- **結果**：40年×10回×方針4つで、系統ごとの平均は 魔法16〜17%・癒し13〜14%・ほか11〜13%・騎兵9〜11%。1回の中でいちばん多い系統は平均16〜19%、いちばん悪い回でも21%（目標の25%より下）。

### ⑤ 新聞の一面
- **わけ**：一面の候補が「世の中の出来事」の年表だけで、そこに敵将の二つ名・昇進・引退が大事件と同じ重さで入っていたため。
- **直し方**（`src/core/newspaper.ts` の `classifyNews`）
  - 話ごとに重み：エンディング20・戦争の終わり15／始まり14・和平の席13・学校防衛戦13・**因縁のある宿敵を討ち取る12**・教え子の戦死11・敵に回った教え子10・宿敵の蘇り9〜11・教え子が領主9・英雄や最上級8〜9・教え子の戦いで地域が動く8・飢饉や国境紛争8 など。いちばん重い話を一面に、ちがう種類の次の話を見出しの2行目に。
  - 新しく**二面**：一面の次に大きな話（4つまで）と、因縁のある宿敵の二つ名・昇進など。
  - **ほかの敵将**の二つ名・昇進・抜擢・引退は、「宿敵と敵将の動き」の欄の下の**「各国の動き」**の小さな欄に、組織ごとに数えてまとめます（例：「帝国軍：昇進2人（クレメンス・テレンス）、新しく名を連ねた将1人（マリウス）」）。政治の欄にも入れません。
  - **1つの号に同じ種類の話は2つまで**（一面と二面を合わせて。宿敵と敵将の動きの欄も、討死・二つ名など同じ印は2つまで）。
  - 前の号に載った話が次の号でくり返されることがあったので、前の号のあとに起きたことだけを載せるようにしました。
  - 「因縁のある宿敵」は、教え子と「因縁」より深い縁（宿敵・仇討ちの誓い・好敵手・友情や恋）のある敵将と、敵に回った卒業生です。

### ⑥ 卒業生の手紙
- 「先生へ」の手紙を、その年にあったことから型を選んで書くようにしました（`src/data/letters.ts` に文、`src/core/alumni.ts` の `alumniLetter`）。題も中身に合わせます（「クレメンスと再会しました」「子どもが生まれました」「近衛になりました」「王国にいるブリットへ」「学校の思い出」など）。
  - その年に起きたこと（結婚・子ども・大きな昇進・宿敵と会った・落ちぶれた）を先に、ほかは昔の仲間・学校の思い出・後輩への助言・弱音などから。
  - 学校の思い出は、書いた子の在学中の年表から、名前つきで（「3年目に、みんなで盗賊団の山猫のルーと戦った日のこと」）。
  - 後輩への助言は、同じ系統の兵種の在校生の名前を出します。
  - **同じ人から同じ型の手紙は続けて出しません**（最後に書いた型を覚えておく）。
- **1年に届く数**：書きたい子を集め、話したいことがある子から先に**12通まで**（`balance.ts` の `letters.yearMax`）。差し入れ・昇格のお知らせ・敵将のうわさは別です。

## 判断したこと
- **評判の「断った国」**：問47の「断った国の評判は下がる」は、もとは国との仲（友好度）のことでしたが、指示書の②で学校の評判を下げる出来事に入っていたので、「1年に4回以上見送り、1つも受けなかった国」だけ評判−2にしました（ふつうに遊んで、どの国の依頼もときどき受けていれば起きません）。
- **評判が低い学校の下がり方**：序盤に戦死や失敗が重なると評判0まで落ちる回があったので、評判40より下では下がり方を小さく（最小で4割）しました。
- **兵種の直し方**：入学の時点の多さが主な原因でしたが、夢や出身国の得意を変えると進路や声かけにも響くので、生まれ方は変えず、「先生の選び方（おまかせ・勧め）」で釣り合いをとりました。自分で選ぶ遊び方は、そのままです。
- **新聞の二面**：もとの紙面に「二面」はなかったので、一面のすぐ下に新しく「二面」の欄を作り、もとの「各組織の移り変わり」は「宿敵と敵将の動き」として、因縁のある宿敵だけにしました。
- **相性の札の言葉**：指示書の2つ目の言い方（「弱点◎」「狙われ注意」「因縁」）にしました。幅360で長い文だと2列のカードに収まらないためです。
- **名前のかぶり**：流れが変わったことで、40年のテストで「死んだはずの敵将が蘇ったとき、その間に同じ名前の人が生まれていた」抜け道が見つかったので、蘇るかもしれない敵将（死んだと思われた・8年以内に討たれた）の名前も取っておくようにしました。
- **テスト**：40年を回すテストが長く止まるため、テストの作業者どうしの連絡が時間切れになる知らせが毎回1件出ていました（テストの失敗ではない）。1年ごとに一息つくようにして、出なくなりました。
- **セーブ**：版を24に上げました。23夜目版のセーブは、そのまま読めます（依頼を断った数の欄を足すだけ。95に張りついた評判も、年ごとに少しずつ落ち着きます）。
- **作業のブランチ**：システムの決まりで作業用のブランチに入れ、指示書どおり `main` にも入れました。
