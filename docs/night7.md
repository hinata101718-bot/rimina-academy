## 2. 作るもの

### ① 日ごとの授業カード（feedback「授業を『パワプロのサクセス』のように … 最終形」）
- **全学年いっしょ、1日1回**。平日5日×4週＋月末の戦闘。**週末と個人指導はなくす**
- 毎日、**約30種類から5種類＋休講**が出る。1つ選ぶ。授業ごとに伸びやすい能力・技能が決まっていて、**全員**伸び、**顔が出ている子は特に伸びる**（約2倍）
- 顔が出る子は毎日ランダム（得意な技能・夢・性格に合う授業に出やすい）。支援C以上の組・恋人・ライバルが同じカードに重なると**友情タッグ✦**（さらに3割増し、支援も上がる、タッグのイベント）
- **目標技能は月に一度**（月の初めに。担任のいる学年は担任の方針で自動・手直し可）。目標技能の授業ではその子がさらに3割増し。顔に「目」の印
- **交流も授業カード**：お茶会・食事会・紅白戦・面談（顔の子から1人、今の面談の会話・3択・特別な面談）・進路指導（3年生だけ、秋以降に出やすい）
- **休講**で全員の体力回復。疲労は「体力」として見せる（顔に「疲」）
- 30種類の案・練習中のイベント・結果の画面・「今週はおまかせ」・年間行事との関係は feedback のとおり
- 1日の操作は10〜15秒。全学年一緒の名簿が見えるよう、カードの顔は小さめ・タップで誰か分かる

### ② 育ち方の作り直し（feedback「育ち方の目標」）
- **完成条件（長期シミュレーションで確認）**：レベル（よく出撃した子）1年目の終わり **Lv10〜15**／2年目 **Lv15〜25**／卒業 **Lv25〜40**。技能ランク：得意 D+〜C → C+〜B → B〜A、2番目 D → C → C〜B+、その他 E+ → D → D〜C、才能は1段上でSも
- **能力は鍛錬ゲージ方式**：伸びの中心はレベルアップ（成長率）。授業で能力ごとのゲージがたまり満タンで+1、卒業までに1つの能力あたり+2〜4。卒業時の目安 HP 35〜45、得意な能力 15〜22、苦手 5〜10。個人ページに鍛錬ゲージ。+1の短い演出
- **兵種試験のレベル条件**：初級 Lv5・中級 Lv15・上級 Lv25・最上級（卒業後）Lv45、英雄（在学中）Lv25。**卒業後の上限 Lv70**。昇格済みの子は降格しない
- 敵のレベル・兵種の段階、依頼の推奨レベル、卒業生の毎年の成長も新しい区切りに合わせる
- 設定「細かな調整」に「技能の伸び方」を追加

### ③ 戦いの記録（feedback「自動の戦闘の見せ方（作り直し）」・見本 battlelog.png）
- 裏の自動のターン制シミュレーションは変えない。**場面の文（劇のような見せ方）をやめ、1回の攻撃ごとのカード**にする：攻撃する側の顔 ▶ 受ける側の顔、「ジーク → 盗賊A」、短い説明（武器・三すくみ・追撃・口上）、右に大きなダメージ（回復は緑の＋、外れはMISS）、必殺・有利・不利・MISSの札、**受けた側のHPゲージ**（減った分を薄い赤で残し、減るアニメーション、18/22）
- 上部に**両軍全員のHPゲージ**の一覧（倒れた子は灰色）
- 「ターン1・味方の番／敵の番」の区切り。反撃・追撃もそれぞれカードに
- 生徒の個性の出来事・敵将の口上・宿敵の出来事は、カードの間の黄色い帯に
- ここぞの判断（1〜2回）は記録の途中で止めて選ばせる（5夜目のまま）
- 速さ：止める／ふつう／速く／結果へ。ふつうで1戦闘1〜2分。雑兵の行動はまとめて短く（「盗賊3人の攻撃：合計−9」）
- 雑兵は兵種のアイコン、敵将は `public/enemies/` の顔、卒業生は生徒のときの顔

### ④ 演出はタップで進む（feedback「レベルアップの演出」）
- レベルアップ・ランクアップ・魔法を覚えた・才能が判明した・鍛錬ゲージの+1 は、**タップするまで次に進まない**（早送り中・おまかせ中・戦いの記録の「速く」中でも止まる）

### ⑤ 会話の噛み合わなさ（feedback「会話が少し噛み合わない」）
- 性格を5つほどのまとまりに分け、組み合わせごとに会話を**まるごと**書く単位を増やす。返事は前のセリフの中身を拾う
- **読み合わせ**：全話題×性格のまとまり×主な分岐で数百本を書き出し（`docs/talk-samples/`）、読んで噛み合わないものを書き直す。直した数と例を報告書に
- 面談（先生と生徒）も同じく

### ⑥ 画面の手直し
- 授業カード・戦いの記録・結果の画面を、名簿と同じ紙のカードの雰囲気で
- ホームのカレンダーを「月〜金＋月末」の日ごとに。今日を強調

### ⑦ 戦争のあと、また戦争が起きる（feedback「戦争が終わったあと、また戦争が起きる」）
- 平和な時代の「毎年2%」をやめ、終わり方ごとの火種と時期（表のとおり）。火種の「くすぶり」を戦況タブに、予兆を新聞・手紙・大事件で
- こちらの動きで火種を遅らせられる仕組み、平和な時代の生徒は戦争を知らない、二度目以降の戦争のエンディング（第二次〜、殿堂・年表に記録）

### ⑧ 仕上げ
- 長期シミュレーションを、新しい授業（オートプレイは授業カードを方針で選ぶ）と戦いの記録で。**60年**×10回×方針4つ（一度目のエンディングのあと「この学校を続ける」で、二度目の戦争と二度目のエンディングが起きるか確かめる）。**②の育ち方の目標**に入っているか、エンディング・在学中の戦死・お金が大きく崩れていないかを `docs/sim-report.md` に
- 主要な画面（授業カード・授業の結果・鍛錬ゲージ・戦いの記録・判断・結果・レベルアップ）を幅390×高さ844で撮影し `docs/screenshots/night7/` に
