# 書き方の決まり（11夜目「言葉の夜」）

画面の文・台詞・戦いの文を書くときの決まりです。新しく書くときも、直すときも、ここに合わせます。
もとになった感想：`docs/feedback.md` の「画面の日本語と台詞が機械的」「戦い・けが・死の描写をもっと生々しく」「学年を跨いだ交流（先輩と後輩）」。

迷ったときの合言葉は、**「声に出して読んで、人がしゃべっているように聞こえるか」**です。

---

## 1. 画面の文の決まり

### 1-1. ふつうの話し言葉で、1文に1つのこと
「〜する。〜する。」の言い切りを並べたり、体言止めを続けたりしません。「です・ます」でやわらかく、1文には1つのことだけ。

- 前：「1つ選ぶ。全員が伸びて、顔が出ている子は特に伸びる。授業は先生の体力を使い、休講で回復する。」
- 後：「授業を1つ選んでください。顔が見えている子は、とくによく伸びます。授業をすると先生は疲れるので、ときどき休講にしましょう。」

### 1-2. 記号を減らす。数字は判断に必要なときだけ
かっこ・中黒（・）・×・%・＋は、なるべく使いません。くわしい数字は「？」を押すと開く説明に移します。

- 前：「今月の目標技能（2つ・金の枠）：目標の授業でさらに伸びます（1つ目は×1.3）。」
- 後：「金の枠の技能が、今月の目標です。この技能を伸ばす授業では、いつもよりよく伸びます。」（「？」の中：「1つ目の目標は1.3倍、2つ目は少しだけ伸びが上がります」）
- 前：「合計の%の確率で、レベルアップのときにその能力が+1。」
- 後：「数字が大きい能力ほど、レベルが上がったときに伸びやすくなります。」

### 1-3. 遊ぶ人の得になることを先に
「何がうれしいか」を先に書き、仕組みはそのあとに。

- 前：「部隊長の腕前（魅力＋軍略）が高いと部隊の命中が少し上がる。」
- 後：「統率の高い子を部隊長にすると、部隊みんなの攻撃が当たりやすくなります。」

### 1-4. 世界の中の声で（短く）
説明は「教官手帳のメモ」や「副官のひとこと」の口調でもかまいません。ただし2文まで。

- 前：「武器は学校の共有物です。…耐久はありません。」
- 後（手帳のメモ）：「武器は学校のもの。使っても壊れないので、遠慮なく持たせてよい。」
- 後（副官）：「先生、今日はどの授業にしますか？　顔が見えている子たちは、とくに張り切っていますよ。」

副官は、生徒とは別の大人の声です。「です・ます」で、先生を立てつつ少しくだけた口調。冗談は言いすぎない。

**管理人オズヴァルト（14夜目：最初の1時間の案内役）**：学校に長くいる老人。一人称「わし」、先生を「教官どの」と呼ぶ。語尾は「〜ですな」「〜ですぞ」「〜なされ」。1回の説明は2〜3文まで。仕組みの名前より「何がうれしいか」を先に言う（例：「札に顔が出ていた子は、とくによく伸びております」）。説教・昔話の長話はしない。

### 1-5. ボタンは動きで
名詞だけのボタンを減らし、押すと何が起きるかを書きます。

| 前 | 後 |
|---|---|
| 出撃 | 出撃する |
| 決定 | この授業にする |
| 面談 | 話を聞く |
| 休講 | 今日は休む |
| 次へ | 次へ進む（戦いの記録の中は「つづき」でもよい） |
| 戻る | 戻る（そのままでよい） |

ボタンは短く、8文字くらいまで。タップする所は44px以上（CLAUDE.md）。

### 1-6. 同じものは同じ言葉で
「3. 言葉の一覧」を使います。一覧にない言葉を新しく作ったら、一覧に足します。

### 1-7. カタカナの仕組みの言葉は、何度も出るものだけ
残すもの：**ゲージ、ランク（技能ランク）、レベル、HP、スキル、タッグ**。
言いかえるもの：ボーナス→上乗せ、ペナルティ→下がる、ステータス→能力、パラメータ→能力、ターゲット→目標、リーダー→部隊長、イベント→出来事、ログ→戦いの記録、ドロップ→戦利品。

### 1-8. 書き終えたら
- 声に出して読む。息つぎが2回いる文は分ける
- 同じ画面で同じ文末（「〜します。」）が3つ続いたら、1つ変える
- 幅360pxで、ボタンの文字が2行にならないか見る

## 2. 台詞の決まり

### 2-1. 部品をつないだ感じをなくす
言葉の途中の「、」や「……」を多用しません。口下手な子でも、言いたいことは伝わる文にします。
- 「……」は**1つの台詞に1つまで**。内気・臆病の子でも2つまで
- どもり（「あ、あの」）は1つの台詞に1つまで
- 前：「……弓が……」「……どうしたら、いいですか。」
- 後：「……弓が、うまく引けないんです。どうしたらいいですか」

### 2-2. 前の台詞を受けて返す
オウム返しだけで終わらせず、一歩踏みこみます。
- 前：「弓のことか。」
- 後：「弓か。このところ、的を外すことが増えたって聞いたぞ」

### 2-3. その場でしか言えない一言を1つ
兵種・最近の戦い・相手の名前・季節・学校の場所（中庭・書庫・厩舎・訓練場・鐘楼・食堂）などを、1往復に1つ入れます。
- 前：「最近どう？」
- 後：「この前の橋の戦い、膝をすりむいてたでしょう。もう走れる？」

### 2-4. 性格ごとの口調表に沿う
「4. 性格ごとの口調表」を見て書きます。1つの会話の中で口調がぶれないこと。

### 2-5. 先生の台詞も決まり文句にしない
説教をくり返さない。締めのあいさつ（「また来なよ。」）は毎回変えるか、なくてもよい。先生は答えを言いすぎず、生徒の言葉を受けて短く返します。
- 締めの例：「冷えてきたな。今日はもう休め」「その弓、明日の朝に見せてくれ」「……そうか。話してくれてよかった」／締めなしで、生徒の一言で終わる

### 2-6. 読み合わせ
話題×性格のまとまり×分岐で書き出し（`docs/talk-samples/`）、声に出して読み、不自然なものを直します。直した数と前と後の例を報告書に。

### 2-7. 戦いの記録の出来事は、その場面で起きたことを受けて出す
- 開戦の場面には、開戦の出来事（意気込み・緊張・武器の手入れ）だけ。成長や結果の話は出さない
- 台詞は直前の文の中身を受ける。「何が」できたのか分かる言葉に
- 前：「マキシムの成長の早さに、教官も目を見張った。」→マキシム「……できた。」（盗賊退治の開戦）
- 後：「マキシムの杖が光り、ジークの肩の傷がふさがった。」→マキシム「……よし、間に合った」
- 策の文は、策を立てた子の**今の武器・兵種・性格**に合わせます
  - 剣・斧・槍：「{c}が刃を高く掲げた」／杖・信仰：「{c}が杖を掲げ、祈りの言葉を唱えた」／弓：「{c}が矢を空へ向け、合図の一本を放った」／魔道：「{c}の手に灯った光を、皆が見上げた」／銃：「{c}が空へ一発撃った」／騎馬：「{c}が馬を前へ出し、隊列の先頭に立った」／武器によらない：「{c}が声を張った」
- 武器・兵種・性別・学年・状態（けが・初陣）と合わない文は、点検の仕組みで調べます（④）

## 4. 性格ごとの口調表

### 共通の決まり
- 生徒は男女どちらもいます。**男女で分けて書けない文では、一人称を省くか、表の「どちらでも」を使います**。男女で分けられる所（`{me}` の性別が分かる会話）だけ、表の男子・女子の一人称を使います
- 先生には、どの性格もふだんは「先生」と呼び、敬語（です・ます）を基本にします。くずし方の度合いが性格の違いです
- 仲間は名前で呼び捨てが基本。真面目だけ「〇〇さん」。後輩から先輩へは「〇〇先輩」、先輩から後輩へはいつもの呼び方
- 生徒は全員18歳以上の大人です。子どもっぽすぎる言葉（「〜でちゅ」「ぼくちん」など）は使いません。恋愛は、告白・両想いなど気持ちの描写まで

### 熱血（hot）まっすぐで声が大きい
| | |
|---|---|
| 一人称 | 男子「俺」、女子「あたし」、どちらでも「こっち」 |
| 先生へ | 「先生！」。元気な「です・ます」（「やりました！」「見ててください！」） |
| 仲間へ | 呼び捨て。「みんな」「お前ら」は乱戦の中だけ |
| 語尾 | 〜だ！　〜だぜ　〜な！　〜ぞ！　「！」は1台詞に2つまで |
| よく使う言葉 | 全力、燃える、任せろ、まだやれる、約束だ |
| 言わない言葉 | 「どうでもいい」「面倒くさい」、遠回しな皮肉、「……」で始める台詞 |
| 例文 | 「中庭で素振り百本、終わったぞ！　次は{you}の番だ！」／「（先生へ）次の出撃、先頭は任せてください！　今度は誰も下がらせません！」 |

### 冷静（calm）いつも落ち着いている
| | |
|---|---|
| 一人称 | 「私」 |
| 先生へ | 「先生」。短く丁寧な「です」（「承知しました」「そう思います」） |
| 仲間へ | 呼び捨て。ときどき「あなた」 |
| 語尾 | 〜だ。　〜だろう。　〜か。　短い言い切り。「！」はほぼ使わない |
| よく使う言葉 | 要点、落ち着け、悪くない、見えた、次は |
| 言わない言葉 | 「やばい」「すっごく」、大声の掛け声、自分をほめる言葉 |
| 例文 | 「霧が出る。弓は届かない。右から回りこもう」／「（先生へ）昨日の講義、兵站の話が一番役に立ちました」 |

### 臆病（timid）怖がりだが慎重
| | |
|---|---|
| 一人称 | 「私」 |
| 先生へ | 「せ、先生……」と最初だけ詰まることがある。丁寧な「です・ます」 |
| 仲間へ | 呼び捨て。年上には「〇〇さん」 |
| 語尾 | 〜かな　〜だよね？　〜だと思う……　どもりと「……」はそれぞれ1つまで |
| よく使う言葉 | こわい、大丈夫かな、気をつけて、ごめんね、もしも |
| 言わない言葉 | 「楽勝」「ぶっ倒す」、人をけなす言葉 |
| 例文 | 「あの、厩舎の裏の道、夜は暗いから……いっしょに行ってもいい？」／「（先生へ）こわかったです。でも、ジークが下がるまでは逃げませんでした」 |

### 皮肉屋（cynic）素直になれない
| | |
|---|---|
| 一人称 | 男子「僕」、女子「わたし」、どちらでも「こっち」 |
| 先生へ | 「先生」。丁寧だがひと言多い（「ご心配なく。……一応、礼は言っておきます」） |
| 仲間へ | 呼び捨て |
| 語尾 | 〜さ。　〜だろ。　〜けどね。　〜でね。　「ふうん」「まあ」で始めることがある |
| よく使う言葉 | まあ、別に、せいぜい、悪くない、柄じゃない |
| 言わない言葉 | 「大好き！」「がんばろうね！」のまっすぐな言葉（本音の場面で1回だけならよい） |
| 例文 | 「書庫の窓際、また占領してるのか。……席、半分空けてやるよ」／「（先生へ）勝ったのは運です。……でも、あの子の矢は本物でしたよ」 |

### おっとり（gentle）のんびり屋で優しい
| | |
|---|---|
| 一人称 | 「わたし」 |
| 先生へ | 「先生」。ゆっくりした「です・ます」（「そうですねえ」「ありがとうございます〜」） |
| 仲間へ | 呼び捨て。ときどき「〇〇さん」 |
| 語尾 | 〜だねえ　〜かなあ　〜よ〜　「〜」は1台詞に1つまで |
| よく使う言葉 | ゆっくり、だいじょうぶ、ほっとする、おいしい、えらいねえ |
| 言わない言葉 | 「急げ」「さっさと」、強い命令、人を責める言葉 |
| 例文 | 「中庭のりんご、今年はよく実ったねえ。休みの日に、みんなで取りに行こうか」／「（先生へ）けがをした子たち、今夜はわたしが様子を見ますね。先生は休んでください」 |

### 真面目（serious）規律を重んじる努力家
| | |
|---|---|
| 一人称 | 「私」 |
| 先生へ | 「先生」。きちんとした敬語（「承知いたしました」「ご指導ありがとうございます」） |
| 仲間へ | 「〇〇さん」。後輩にも「さん」 |
| 語尾 | 〜です。　〜ます。　〜でしょうか。　〜べきです。 |
| よく使う言葉 | 規律、鍛錬、心得、務め、恥じない |
| 言わない言葉 | 「まあいっか」「適当に」、くだけた若者言葉 |

## 5. 戦の描写

### 5-1. ねらいと語り口
- 派手さのためではなく、**戦の痛みと、失う重さ**を伝えます
- 軍記ものの語り口：**短い文**、**体の動き**、**音**、**血**、**最期の言葉**。1文に1つの動き
- 「！」は掛け声だけ。地の文には使いません（「{a}の会心の一撃が決まった！」→「{a}の刃が、兜の下へ吸いこまれた」）
- 位置の動きも文で：「騎馬で回りこみ、背後を突いた」「橋の上で押し返した」
- 設定「戦の描写」の**濃い**（はじめの設定）でこの節のとおりに書き、**ふつう**では血・傷の細かい所を一つ省いた文にします

### 5-3. 重傷（生徒）
どこを、どうやられたかを書きます。そのあと、運ばれる場面と仲間の声。

- 「{a}は脇腹を深く裂かれた。押さえた指のあいだから、血が止まらない」
- 「{b}が駆け寄り、{a}を背負った。『しっかりしろ、まだ目を閉じるな！』」
- 「{a}は担架で後ろへ運ばれていった。泥に、赤い筋が残った」
- 療養：「包帯を替えるたび、{a}は唇をかんだ」「熱が三日下がらなかった。夜、{a}は天井を見たまま、眠れずにいた」
- 療養中の会話（性格で）：熱血「寝てる場合じゃないのにな……悔しい」／冷静「傷は浅くない。焦らず治す」／内気「……みんなの足音、ここまで聞こえるの」
- 傷跡：年表「{battle}の戦いで、左肩に傷を負った」。会話でときどき触れる（「この傷、雨の日はまだうずくんだ」）

### 5-4. 戦死（生徒）
**静かに、重く。** 判は押さず、画面は暗く（9夜目のまま）。最期の数行は「倒れる→駆け寄る→最期の言葉→事切れる」の順。

- 「{a}の体が、ゆっくりと前に傾いた」
- 「{b}が名を呼びながら駆け寄る。抱き起こした腕が、血で濡れた」
- 最期の言葉（性格で。短く、その子らしく）
  - 熱血「……悪い、先に……行く。みんなを、頼んだ」
  - 冷静「……泣くな。お前は……退け。それが正しい」
  - 臆病「……こわく、ない。もう、こわくないよ」
  - 皮肉屋「……ほら、言っただろ。柄じゃないって……」
  - おっとり「……先生に、ありがとうって……伝えてね」
  - 真面目「……務めは、果たせ……ましたか」
  - 陽気「……ねえ、笑ってよ。……最後くらい」
  - 内気「……ここに、いて。……それだけで、いい」
  - 負けず嫌い「……まだだ、まだ……負けて、ない……」
  - 気まぐれ「……いい風。……今日は、ここまでかな」
- 「それきり、{a}は動かなかった」「{a}の手から、剣が落ちた」
- 亡骸と遺品：「{b}たちは{a}を外套に包み、馬の背に乗せた」「残されたのは、刃こぼれした{weapon}と、書きかけの手紙だった」
- その夜の学校：「食堂に、{a}の席だけが空いていた。誰も、その椅子を引かなかった」「鐘楼の鐘が、一度だけ鳴った」

### 5-5. 敵将の最期と、討った子の受け止め方
- 口上つきの最期：「『見事だ……若いの。我が首、持っていけ』――{d}はそう言って、刀を地に突いた」「『国に、娘がいる……』それが{d}の最後の言葉だった」
- 討った子（性格で）
  - 熱血：剣を握ったまま、しばらく荒い息をついていた
  - 冷静：黙って敵将の目を閉じさせた
  - 臆病：手の震えが止まらない。{a}は、その場にしゃがみこんだ
  - 皮肉屋：「……勝ったのに、全然すっきりしないな」
  - おっとり：小さく祈りの言葉を唱えた
  - 真面目：敵将の名を、手帳に書き留めた
  - 陽気：いつもの笑い声が出なかった
  - 内気：その夜、何も口にしなかった
  - 負けず嫌い：「……強かった」とだけ言った
  - 気まぐれ：敵将の外套の砂を、そっと払った
- 夜、吐き気・眠れない・先生に話しに来る、などの短い場面につなげてよい

### 5-5b. 生々しく書くのは、死と大けがの場面だけ（14夜目。ヒナタさん指定）
- 「濃い」「凄惨」の生々しい描写は、**名前のある者の死**（生徒・卒業生・敵将・名を得た兵）、**重傷**（運ばれる・療養）、**敵将を討ち取った場面**だけ
- **ふだんの攻撃**（当たった・外れた・小さなけが）は短くあっさり：「ジークの攻撃！」「盗賊Aに12のダメージ！」に、武器ごとの短い一言を添える程度（「刃が肩をかすめた」）。血・骨・はらわたの言葉は使わない
- **名前のない雑兵を倒したとき**も短く（「盗賊Aは倒れた」「崩れ落ちた」）。凄惨でも1行まで
- **必殺**は勢いの表現で（「渾身の一撃！」）、むごさは入れない（その一撃で名前のある者が倒れたときだけ、上の決まりへ）
- 画面の血しぶき（凄惨）も、名前のある者が倒れる場面と、生徒が倒れる場面だけ

### 5-5c. 攻撃のあとの結果で、4つの段に分ける（16夜目。feedback「『串刺し』なのに生きている」）
戦いの文は、**その攻撃のあとの結果**で選びます。死ぬほどの言葉なのに生き残る、という文を出さないためです。

| 段 | いつ | 書き方 | 例 |
|---|---|---|---|
| 1. ふつうの当たり | まだ元気（HPが3割より上） | かすめる・浅く斬る・打ちすえる | 「刃が肩をかすめた」「矢が{d}の腕に突き立った」 |
| 2. 深手 | HPが少なくなった（3割以下）が、まだ立っている | 深く斬られる・血がにじむ・膝をつく。**命にかかわる言葉は使わない** | 「重い一太刀に、{d}がよろめいた」「{d}はひざをついた……」 |
| 3. 重傷 | 倒れて戦いから退く（生徒の重傷・逃げのびた敵将・退いた敵の卒業生） | **助かった理由をひとこと入れる**（急所はわずかに外れていた・鎧が受け止めた・仲間がすぐ血を止めた など） | 「{a}は腿を穂先に深く貫かれたが、急所はわずかに外れていた」 |
| 4. 死 | 戦死・討ち取り・雑兵が倒れる | ここだけ、下の「死ぬ段の言葉」を使ってよい | 「胸を貫かれた{a}は、そのまま崩れた」 |

**死ぬ段の言葉**（1〜3の段には出さない。`src/data/warprose.ts` の `DEATH_WORDS`、点検は `scripts/check-text.ts` とテスト）：
串刺し・貫通・射抜い・貫いた／貫き・首を・首が・喉・心臓・事切れ・息絶え・息を引き取・絶命・黒い塊・動かなくなった・もう動かない・まま動かない・二度と・最後の言葉・亡骸・命を落と・死・頭を割・兜ごと割・胸を撃ち抜・腹を撃ち抜・目を閉じた・もう冷た・もう答えはなかった・血だまりに沈・声もなく倒れ・崩れ落ち（雑兵・死の段だけ）

- 3の段（重傷）では「貫かれた」「深く斬られた」も使ってよいが、そのときは**必ず**助かった理由を添えます（「深く貫かれたが、急所はわずかに外れていた」）
- 敵将が倒れたあと逃げのびるときも3の段（「深手を負ったが、急所はわずかに外れていた。兵に担がれて逃げのびた」）。逃げのびるかどうかは、倒れたその場で決まります

### 5-6. 描写の3つの段（設定「戦の描写」）
- **ふつう**：9夜目までの程度。当たった・倒れた、が分かる文。
- **濃い**（はじめ）：上の5-2〜5-5。体の動き・音・血を短く。1つの場面に血の言葉は2つまで。
- **凄惨**（選ぶときに一度だけ「むごい描写が増えます」と確かめる）：濃いに足して、斬り落とされる手足・骨がのぞく傷・砕けた顔などの**傷そのもの**、血しぶき・血だまり、死にゆく者のうめき、戦のあとの戦場（転がる亡骸、鳥の声）。画面にも、必殺・撃破で血しぶきの飛沫が散り、生徒の戦死は血だまりに沈むように暗くなる（顔の絵そのものは変えず、上に重ねるだけ）。
  - 例（剣・凄惨）：「刃が{d}の腕を断った。落ちた腕がまだ剣を握っている」
  - 例（斧・凄惨）：「斧が兜ごと頭を割った。{d}は声も上げずに崩れた」
  - 例（戦死・凄惨）：「{a}の腹から、押さえた指のあいだを血があふれ続けた。『……寒い』。それが最後の言葉だった」

### 5-7. 書かない線
次のものは、どの段でも（凄惨でも）書きません。重さは**痛み・別れ・残された者**で出します。

- **拷問やなぶり殺し**の細かい描写（何をどうしたか、苦しむ様子を長く書くこと）
- **捕虜や民へのむごい仕打ち**の細部（「村が焼かれた」「捕虜がひどい扱いを受けたらしい」と結果を一言で伝えるまで）
- 「ふつう」「濃い」では、**体がばらばらになる**ような細部（首や手足が飛ぶ、内臓が出る、など）。これは「凄惨」だけ
- 死体をもてあそぶ描写、子どもへのむごい仕打ち
- 傷をおもしろがる文、死をからかう文、討った数を自慢する台詞（敵将の口上で悪役として言わせるのは1言まで）
- 顔の絵に血を描きこむこと（血の色は演出の斬撃と飛び散る欠片だけ、9夜目より少し濃く）
- 性的な暴力。恋愛は気持ちの描写まで（告白・両想い）。生徒は全員18歳以上

書き方の目安：**1つの場面に、血の言葉（血・赤い・濡れる）は2つまで**。痛みは「歯を食いしばる」「息が荒い」など体の動きで見せ、傷の中身は書きすぎない。
