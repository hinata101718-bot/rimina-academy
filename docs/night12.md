## 0. いちばん大事なこと
1. **質問で止まらないこと。** 迷ったら `docs/feedback.md` → `docs/design.md` → `docs/hearing.md` の順に意図を読み、判断して進め、判断を報告書に書く。物差し：「手応え」と「発見」。

3. 段階ごとに `npm test` と `npm run build` を通してコミット・プッシュ。途中の公開でゲームが止まらないこと。
4. **既存のセーブデータを壊さない。** 11夜目版（形式11）のセーブのテストを足す。今いる生徒・卒業生は、今の技能ランクまでのスキルを覚えた状態にする（演出なし）。
5. **シミュレーション**：戦いの数字が変わるので、CLAUDE.md の「時間を短くする決まり」に従い、調整は小さなものさし、最後に長いシミュレーション（40年×10回×方針4つ）を1回。`docs/sim-baseline.json`（10夜目）と比べ、在学中の戦死・勝率・お金・エンディング・宿敵が大きく崩れていないこと。

- `docs/reports/night10.md`・`night11.md`、`docs/writing-style.md`（技の名前と文はこの決まりで）

## 2. 作るもの
### ① 戦技と心得のデータ
- すべての技能（剣・槍・斧・弓・格闘・魔道・信仰・騎乗・重装・飛行・軍略・統率…）で、E+・D・C・B・A・S あたりに1つずつ。戦技（攻撃の技・自動で使う）と心得（いつも効く）。名前はオリジナル。**データを足すだけで増やせる作り**
- 得意技能は1つ早く、開花した子はその技能の固有の戦技
### ② 戦いに入れる
- 裏のマス目の戦いの計算に足す（戦技は自動で使う。ここぞのときに使いやすい）。文の窓に「ジークの『燕返し』！」と技の名前の帯（必殺ほど大きくない）
- 持てる数の上限（戦技3・心得5）、付けかえはおまかせ（個人ページ「技能」タブで変えられる）。兵種スキルは別枠
- 敵将・卒業生も持つ（組織図の札・出撃前のヒント「燕返しの使い手」）、卒業生講師が教えることも
### ③ 見せ方
- 覚えた瞬間はタップで進む演出、技能タブに覚えた・まだの一覧（まだは「剣Bで？？？」）、兵種図鑑・評価の称号とのつながり
### ④ 10夜目の残りの調整（ヒナタさん了承）
- **銘入りの武器を減らす**：今は敵将を討つと必ず手に入り、40年で約300振り（1年に7〜8振り）と多すぎる。**ふつうの隊長は3割ほど**、**宿敵・因縁のある敵将・幹部以上・将軍（頭目）を討ったときは必ず**。手に入ったときの演出は今のまま。すでに持っている銘入りの武器はそのまま
- **在学中の戦死が9夜目より多い**（40年で平均1.7人→2.6人）：10夜目の報告書の次の手どおり、敵の伸びを少し下げて9夜目に近づける（②の戦技・心得の調整と一緒に、長いシミュレーションで確かめる）
- おまかせの最初のエンディングが遅くなった（20.0→27.5年）件も、戦死の調整のあとで見る（大きく外れていれば報告書に次の手を）

### ⑤ 仕上げ
- 長いシミュレーション、撮影は最後にまとめて1回（`docs/screenshots/night12/`）
