    - **出世**：今はおもにレベルで決まる卒業生の昇進（階級が上がる）に、武官は**統率**、参謀は**軍略**のランクを大きく効かせる（統率Aの子は将軍まで上りやすい）。卒業後も毎年、道に合った技能が少しずつ伸びる
    - **国への影響**：卒業生が国力・戦況に与える力（武官・参謀の上乗せ）を、統率・軍略のランクで変える。統率の高い将が率いる国は戦に強く、軍略の高い参謀がいる国は無駄な戦を避けやすい（和平にも少し効く）
    - **敵になった教え子**：敵国に仕えた卒業生は、統率が高いほど組織図の上の段（幹部・将軍）に就きやすく、軍略が高いと**策を使ってくる敵将**になる（戦いの記録に「かつての教え子が策を見抜いた」）
    - **援軍**：味方として援軍に来た卒業生は、統率・軍略に応じて部隊の命中の上乗せや、策の見込みの上乗せをくれる
    - **講師**：卒業生を講師に呼ぶと、統率・軍略の高い子は「指揮の演習」「戦術論」をよく教える
    - 手紙・新聞・年鑑に「第三軍の参謀に」「北方軍を率いる将に」のように出る。卒業時の個人の年表にも
  - **統率が低くても戦いに強い子**（ヒナタさんの問い）：強さを**2つの軸**で見る。**個の武**（レベル・能力・武器の技能）と**采配**（統率・軍略）。どちらか一方でも活躍できる
    - 卒業後の道を3つに：**将の道**（統率）、**参謀の道**（軍略）、**勇士の道**（個の武。近衛・先鋒・剣豪・名うての傭兵）
    - 勇士の道の子は、階級は隊長どまりになりやすいが、**武勲で名を上げる**：二つ名がつきやすい、一騎打ち・決闘の出来事、新聞に「〇〇、単騎で敵陣を破る」。国への影響は、戦いの山場での勝ちやすさに効く（将は戦い全体、勇士は山場）
    - 統率の低い子が将になると、まれに失敗の出来事（「兵がついてこなかった」）。逆に戦いが苦手でも統率・軍略の高い子は、後ろから采配する将・参謀として出世できる
    - **敵将も同じ2つの軸**：勇士型の敵将は本人がとても強いが、倒れると兵が崩れやすい（一騎打ちの申し込みがよく効く）。将型の敵将は兵がよく動くが、本人は討ちやすい（伏兵・挟み撃ちが効く）。組織図の札と、出撃前のヒントに「武勇に優れる」「采配に優れる」
    - 個人ページ「記録」タブ・卒業式に、その子の向き（将・参謀・勇士）を一言で（「この子は、兵を率いるより自分で道を切り開く」）
- [ ] 出撃前の選ぶ欄は、名前の横に**技能ランクと一言**（「マキシム　統率C　部隊の命中が少し上がる」「マキシム　軍略E+　策が決まりやすい」）。いちばん向いている子に「おすすめ」
- [ ] 欄の横に「？」：タップで、統率・軍略が何に効くか、どうすれば伸びるか（「戦術論の授業で軍略が伸びます」）
- 隠れた才能をなくす（同じ10夜目）ので、「軍師の才」と、策を覚える条件「才能が分かった子」は、**軍略が得意の子・軍略の芽が開花した子**に置きかえる

### 画面の日本語と台詞が機械的（11夜目「言葉の夜」。ヒナタさん希望）

  2. **かっこ・中黒・×・%・＋の記号を減らす**。数字は判断に必要なときだけ。くわしい数字は「？」の中へ
  3. **遊ぶ人の得になることを先に**（「顔が出ている子は、とくによく伸びます」が先、仕組みはあと）
  4. **世界の中の声**で：説明は「教官手帳のメモ」や「副官のひとこと」の口調でもよい（「先生、今日はどの授業にしますか？　顔が見えている子たちは、とくに張り切っていますよ」）。ただし短く
  5. ボタンは**動き**で（「出撃する」「この授業にする」）。名詞だけのボタンを減らす
  6. 同じものは同じ言葉で（「技能」「技能ランク」、「体力」「スタミナ」などの混ざりをなくす）。言葉の一覧を `docs/writing-style.md` に

  1. **部品をつないだ感じをなくす**：「……弓が……」「……どうしたら、いいですか。」のような、言葉の途中の不自然な読点・「……」の多用を減らす（口下手な子でも、言いたいことは伝わる文に）

  5. **先生の台詞**も、説教や決まり文句（「また来なよ。」）をくり返さない。締めのあいさつは毎回変える・なくてもよい
  6. 読み合わせ：話題×性格のまとまり×分岐で書き出し（7夜目の `docs/talk-samples/` を使う）、声に出して不自然なものを直す。直した数と前と後の例を報告書に
