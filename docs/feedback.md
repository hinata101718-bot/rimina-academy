## 2026-11-08（1夜目版を遊んで）

### 戦闘
- [ ] 敵のターンが早くて、何が起きたかわかりづらい
  - 案：敵の行動を1体ずつ、間をあけて見せる。動く敵にカーソル（枠）を合わせ、移動先へ1マスずつ動かし、攻撃対象を光らせてから結果を出す。初期速度を「ゆっくり」寄りに。早送り・スキップは残す
- [ ] 戦ったときに、お互いの体力ゲージが減っていく演出がほしい
  - 案：攻撃のたびに両者のHPバーを並べて表示し、命中したら減る様子を0.5秒ほどかけて見せる（数値ポップのときも、マップ上の小さなHPバーが減っていく）。反撃・追撃も順番に
- [ ] レベルアップの演出がほしい
  - 案：戦闘中・戦闘後のレベルアップ時に、似顔絵と「LEVEL UP!」、上がった能力を1つずつ「+1」で光らせる（FE風）。効果音つき

- [ ] 経験値や技能ランクも、ゲージが上がっていく演出がほしい
  - 案：戦闘後・授業後・個人指導後に、経験値ゲージ（0〜100）と技能ランクのゲージ（次のランクまで）が伸びていく様子を見せる。満タンになったらレベルアップ／ランクアップ（例「剣 D→D+」）の演出へつなぐ。週のまとめでは、伸びた子だけ短く見せ、長くなりすぎないように

### 支援会話
- [ ] 会話が最初から全部見えている。タップで1行ずつ進めたい
  - 案：1セリフずつ表示し、タップで次へ（文字は少しずつ流れて出る、タップで一気に表示→次のタップで次の行）。話している側の似顔絵を明るく、聞いている側を少し暗く。「すべて表示」「スキップ」も用意。読み返し（下記）ではまとめて表示でよい
