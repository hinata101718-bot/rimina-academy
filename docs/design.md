## 0. ゲームの一行説明

三国の国境に取り残された廃校寸前の士官学校で、教官として落ちこぼれたちを3年かけて育て、三国へ送り出す。卒業生は出世して戦況を動かし、ときに戦場で再会する。教官は歳を取り、教え子に学校を託す。**大陸の戦争が終わった年がエンディング**。

- 手本：主＝ファイアーエムブレム 風花雪月（1ヶ月の流れ・支援・兵種・戦闘）、副＝パワプロ 栄冠ナイン（毎年入れ替わる自動生成の生徒、隠れ能力、速い1年）
- 対象：まずヒナタさん個人用。固有名詞はすべてオリジナル（風花雪月の名前・紋章の仕組みは使わない）
- 端末：iPhone（Safari）優先の縦画面。PCでも遊べる（横が広いときは2列表示）

## 1. 世界観と固有名詞

### 1.1 大陸と三国
- 大陸：**リンデルガ大陸**。魔法が残る架空の中世末期。銃は物語の途中で現れる新兵器
- 歴史：王国と同盟は、かつて大陸を治めた帝国から分かれて独立した。学校は分裂前の帝国時代に建てられた分校で、三国の国境が接する辺境にあり、どの国にも属さない

| | ヴィンターガルト王国 | ソラリウス帝国 | フィオレンツァ同盟 |
|---|---|---|---|
| 位置・気候 | 北、寒冷 | 南西、大陸の中心を自負 | 東、交易の要衝 |
| 価値観 | 騎士道・伝統・家柄 | 改革・実力主義・統一の野望 | 諸侯の合議制・交易・調和 |
| 得意兵種 | 騎兵系・重装系 | 歩兵・銃・魔道 | 弓・飛行・回復 |
| 待遇 | 出世は家柄次第 | 給料高・出世早いが前線送り多い | 給料良いが諸侯の顔色次第 |
| 戦争への姿勢 | 守り | 火種（大陸の再統一が大義） | 様子見、和平の窓口 |
| 銃への態度 | 騎士の誇りから嫌う | 最初に手に入れる | 交易で仕入れて売る |
| 名前の響き | ドイツ・北欧風 | ラテン風 | イタリア・フランス風 |
| 好む生徒 | 貴族、礼儀正しい | 貧しい出、野心家 | 頭が良い、魔法の才能 |

- 帝国を単なる悪役にしない：「かつて一つだった大陸を取り戻す」「痩せた土地で民が飢えている」などの事情を持たせる
- 学校：**ソラリウス帝立士官学校 リミナ分校**（リミナ＝ラテン語の「境界」由来）

### 1.2 雰囲気
- **戦況（大陸の緊張度）に連動して変わる**：平和期＝青春寄り、緊張期、激戦期＝戦記寄り。年数ではなく緊張度で決まる
- 平和期：お茶会や手合わせのイベント多め、依頼は盗賊・魔物退治
- 緊張期：戦災孤児の入学が増える、卒業生の配属先が前線に
- 激戦期：学校防衛戦、訃報、故郷の国へ帰りたがる生徒

### 1.3 名前の自動生成
- 国ごとに名・姓のリスト（各国 男女名それぞれ60以上、姓40以上）を `src/data/names.ts` に用意
- 王国：ジークハルト、エーリカ、ヴォルフ… ／ 帝国：アウレリウス、セレナ、ルキウス… ／ 同盟：ルカ、ミレーヌ、ジュリオ…
- 貴族は姓に「フォン」「デ」などの国ごとの接頭辞をつけてよい

## 2. 時間の構造

### 2.1 単位
- 1年＝12ヶ月（4月始まり〜3月）。1ヶ月＝4週＋月末の戦闘
- 1週間の流れ：①週の始め（授業方針の確認）→②平日（個人指導 基本3回）→③週末（交流1〜2回）→④週のまとめ
- 目安：1週間＝1〜2分、1ヶ月＝5〜10分、1年＝60〜90分、戦闘1回＝10〜15分
- **毎週の終わりに自動セーブ**。戦闘中は**ターンごとに自動セーブ**

### 2.2 年間行事
| 月 | 行事 | 内容 |
|---|---|---|
| 4月 | 入学試験・入学式 | 志願者から合格者を選ぶ（§10.1） |
| 7月 | 夏の合宿 | この月だけ授業の伸び×1.5、疲労の増え方×1.5 |
| 9月 | 公開演武会 | 月末の戦闘が演武会（模擬戦）になる。三国の関係者が観戦し、活躍した生徒に各国から「声かけ」（§10.3） |
| 12月 | 冬の収穫祭 | 週末の交流が1回多い、支援値の上がり方×1.5 |
| 3月 | 卒業試験・卒業式 | 進路決定、卒業式（§10.4）、年度末処理（§11, §12） |

### 2.3 年度末処理（3月の最後）の順番
1. 卒業試験・進路決定・卒業式
2. 在校生の学年を1つ上げる
3. 卒業生シミュレーション（§11）
4. 戦況の年度末更新（§12）
5. 新聞の発行（§16.5）
6. 教官の加齢・引退の判定（§14）
7. エンディング判定（§15）
8. 廃校期限の判定（§5.5）
9. 4月：入学試験へ

## 3. 生徒

### 3.1 人数と在籍
- 在籍3年（1年目＝基礎、2年目＝兵種を決める、3年目＝上級兵種と進路）
- 1学年の定員は評判で増える：初年度6〜8人 → 最大**10人**。3学年で最大30人
- 入学年齢18〜20歳（まれに23〜26歳の年上も）。**生徒は全員成人**
- 性別は入学ごとにおよそ半々でランダム。兵種に性別制限なし

### 3.2 能力値（FE準拠8種＋魅力）
`HP・力・魔力・技・速さ・幸運・守備・魔防・魅力`
- 入学時の目安：HP 18〜26、他 2〜8（魅力も同様）
- **成長率**（各能力、%）：基本 15〜60%。生徒ごとにランダム＋出身・才能・特徴タグで補正。兵種の成長補正を加算
- 能力値の上限：在学中は各 30（HPは60）。卒業後は最大レベル50まで成長
- レベル：**通しレベル**（兵種が変わってもリセットしない）。経験値100で1レベル上がり、各能力が成長率の確率で+1

### 3.3 技能ランク
- 技能：`剣・槍・斧・弓・魔道・信仰・騎乗・重装・飛行`（銃登場後に `銃` を追加）
- ランク：E, E+, D, D+, C, C+, B, B+, A, A+, S（技能ポイント制。閾値例：E=0, E+=20, D=50, D+=90, C=140, C+=200, B=270, B+=350, A=440, A+=540, S=650）
- 技能ポイントは授業・個人指導・戦闘で増える（§6）
- 武器はランクが足りないと装備できない

### 3.4 状態：やる気と疲労
- **やる気**：5段階（とても低い／低い／普通／高い／とても高い）。授業・指導の伸びに掛け算：0.8 / 0.9 / 1.0 / 1.1 / 1.2
- **疲労**：0〜100。授業で毎週+8、個人指導の技能指導+10、手合わせ+10、夏合宿は×1.5。毎週自然回復−5（礼拝堂の段階で−5/−8/−11/−14）
  - 疲労60以上：伸び×0.8
  - 疲労100到達：**体調不良**で翌1週間休み（授業・指導・交流・出撃不可）、疲労は40に戻る
- やる気が下がる：目標技能が夢とずれている（毎月少し）、相談を断る、仲間の退学・戦死、疲労60以上が続く
- やる気が上がる：面談、夢に沿った指導、演習・戦闘での活躍、お茶会・食事会

### 3.5 個性（自動生成）
- **性格**（10種）：熱血、冷静、臆病、皮肉屋、おっとり、真面目、陽気、内気、負けず嫌い、気まぐれ。会話の口調・お茶会の反応・小さな戦闘補正（§8.10）
- **夢**（例）：王国の騎士になりたい／家族を養いたい／学者になりたい／名を上げたい／故郷を守りたい／平和な世界にしたい／特になし。進路の希望と、目標技能の「夢との一致」判定に使う。夢ごとに「沿う技能」「行きたい国」「向く道（武官・参謀・文官）」を定義
- **出身**：国（三国、まれに辺境の村）＋家柄（貴族／平民／孤児）。名前・髪色傾向・行きたい国・会話の話題
- **特徴タグ**（1〜3個）：成長や戦闘に具体的効果があるもの。例：
  - 早熟（1年目の成長率+10%、3年目−10%）／遅咲き（1年目−10%、3年目+15%）
  - 負けず嫌い（HP半分以下で攻撃+3）／本番に強い（実戦で命中+10）／臆病（敵3体以上に隣接されると回避−15）
  - 努力家（授業の伸び×1.1）／怠け者（授業の伸び×0.9、個人指導は×1.2）
  - 人懐っこい（支援値の上がり方×1.3）／一匹狼（支援補正を受けない代わりに単独で回避+10）
  - 幸運の星（戦死判定で重傷になる確率+20%）
- **隠れた才能**（§3.6）

### 3.6 隠れた才能（少しずつ分かっていく）
- 入学時に見えるのは**現在の能力値・技能ランク・性格・夢・出身・一部の特徴タグ**。成長率と才能は「？」
- 才能の例：「○○の天才」（特定技能の伸び×1.5、該当能力の成長率+15%）、「隠れた統率者」（魅力成長+20%）、「英雄の器」（ごくまれ：全成長率+10%、隠し兵種「英雄」の条件）
- **判明の段階**（才能ごとに「判明度」0〜100）：
  - 授業で毎週+2（書庫の段階で+1ずつ追加）
  - 個人指導（教官）+15、副教官の指導+8、面談で兵種の話題 +10
  - 演習・戦闘でその技能を使って活躍 +10
  - 判明度30：「○○が伸びやすい気がする」（ヒント1）／60：「○○の才能があるかもしれない」（ヒント2）／100：才能タグ確定、成長率も表示
- 教官の「経験」（§14.1）が高いほど判明度の上がり方が増える

### 3.7 見た目
- **パーツ組み合わせの簡易似顔絵（SVG）**：輪郭・髪型（10種以上）・髪色（8色）・目（5種）・肌色（4種）・服の色（国ごと）を組み合わせる
- 出身国ごとに髪色・服色の傾向をつける
- **顔画像への差し替え口**：`public/faces/{国}_{性別}_{髪色}_{番号}.png` が存在すれば、条件に合う顔画像を割り当てる（ChatGPTで描いた画像を後から追加する想定）。なければSVG似顔絵
- 卒業生の子は親と同じ髪色（と可能なら同じ髪型）を受け継ぐ
- 設定で名簿を「色の丸＋頭文字」表示に切り替え可能

### 3.8 人数が増えたときの工夫
- **今月の主役**：毎月1〜2人に、その子だけの小さな出来事（悩み、家族からの手紙、特訓の申し出、など）。しばらく注目されていない子（最後に主役・指導・面談を受けてからの週数が長い子）を優先し、3年間で全員に必ず複数回回る
- **気にかける生徒**：最大5人をピン留め。ホームに常時表示
- **変化があった子だけ知らせる**：才能のヒント・判明、やる気低下、疲労80以上、兵種試験が受けられる、退学の予兆、相談がある、などをやること一覧に名前付きで表示

### 3.9 途中退学
- 自主退学のみ（退学処分はなし）。頻度は年0〜1人程度
- 予兆→実行の2段階。予兆が出てから4〜8週以内に面談すれば解消（信頼が高いと1回で、低いと2回必要）
- 理由：やる気が「とても低い」が長く続く／家の事情（ランダム、まれ）／他国からの引き抜き（才能判明済みの子）／故郷の国が戦場に（激戦期）
- 信頼（§7.2）が高い子は、去る前に必ず相談に来る

## 5. 学校経営

### 5.1 お金（G）
- 初期資金：800G（廃校寸前）
- **収入**
  - 実戦依頼の報酬（200〜1500G、§9）
  - 年度末：三国からの援助金＝各国について（その国に所属する現役卒業生の役職ポイント合計×20G＋友好度×5G）、0未満は0
  - 年度末：評判に応じた寄付＝評判×15G
- **支出**
  - 講師の給料（月150〜400G、§5.3）
  - 施設の修繕・増築（§5.2）
  - 武器・道具の購入（§8.6）
- 所持金がマイナスにはならない（支払えない給料は講師が去る）

### 5.2 施設（5種×3段階、開始時はすべて「ボロボロ＝0段階」）
| 施設 | 効果（段階1/2/3） | 費用（段階1/2/3） |
|---|---|---|
| 訓練場 | 剣・槍・斧の伸び+10/20/30% | 600/1500/3000G |
| 書庫 | 魔道の伸び+10/20/30%、才能の判明度+1/+2/+3（毎週） | 600/1500/3000G |
| 厩舎 | 騎乗・飛行の伸び+10/20/30%。段階1以上で騎兵系・飛行系の兵種試験が受けられる | 800/1800/3500G |
| 礼拝堂 | 信仰の伸び+10/20/30%、疲労の自然回復+3/6/9 | 600/1500/3000G |
| 食堂 | やる気が週ごとに下がりにくい、交流イベントの発生+10/20/30% | 500/1200/2500G |
| 射撃場（銃登場後） | 銃・弓の伸び+10/20/30% | 800/1800/3500G |

### 5.3 講師
- 授業は「担当者」がいる科目ほどよく伸びる。担当者＝教官／雇った講師／卒業生講師
- 雇う講師：毎年4月に2〜3人の候補（得意技能とランク、月給）から雇える。月給150〜400G
- 卒業生講師：進路「学校に残る」を選んだ卒業生は講師見習い（1年）→講師→副教官（§14.3）。給料は雇う講師の半額
- 担当者のいない科目は伸びが×0.5

### 5.4 評判（0〜100）
- 開始時10
- 上がる：実戦依頼の成功（+1〜3）、演武会での活躍（+2〜5）、卒業生の昇進（年度末、役職ポイントに応じ+1〜5）、卒業生の英雄的活躍
- 下がる：実戦依頼の失敗（−2）、在学中の戦死（−3）、退学（−1）
- 効果：入学志願者の数と質、1学年の定員（評判20で8人、40で9人、60で10人）、寄付

### 5.5 廃校の期限（序盤の目標）
- 「3年目の年度末までに評判40以上」が目標
- 達成できなければ、**最も友好度の高い国の傘下に入って存続**（同点なら援助を申し出た国＝卒業生が多い国）
  - 傘下の国以外の依頼が来にくい、傘下以外の国から声かけが減る、他国の友好度−20
  - 和平エンド・中立宣言エンドの条件を満たすには、独立の回復が必要
  - 帝国傘下：援助金+50%だが卒業生の前線送り増。王国傘下：家柄の良い志願者増。同盟傘下：予算そこそこ・外交イベント増
- **独立の回復**：評判70以上で年度末に独立を宣言できる（傘下国の友好度−30）

## 6. 1週間の行動

> **7夜目に作り直し（この章の6.1〜6.3は6夜目までの仕組み）**：授業は「日ごとの授業カード」になった。全学年いっしょに平日5日×4週、毎日約30種類から5種類＋休講が出て1つ選ぶ。全員が伸び、顔が出ている子は約2倍、今月の目標技能の授業はさらに×1.3、友情タッグ（支援C以上・恋人・ライバルが同じカード）はさらに×1.3。交流（お茶会・食事会・紅白戦・面談・進路指導）もカード。週末と個人指導はなくなった。疲労は「体力」として見せ、休講で回復。能力は鍛錬ゲージ（満タンで+1）。「今週はおまかせ」で金曜まで進められる。数字は `src/data/balance.ts` の `day`、授業の一覧は `src/data/lessons.ts`。育ち方の目標と兵種試験のレベル条件（Lv5/15/25/45、上限70）は感想メモのとおり。

### 6.1 授業（週の始めに確認）
- **学年ごとに月の重点科目を2つ**選ぶ（月の初めに設定、未設定なら前月のまま）
- **生徒ごとに目標技能を2つ**（いつでも変更可）
- 毎週の技能ポイントの伸び（1人あたり）：
  - 重点科目：+6（各科目）
  - 目標技能：+8（各技能）
  - 重点と目標が同じ技能なら両方加算
  - これに掛ける：担当者のランク補正（担当者の該当技能ランク E=0.6 / D=0.8 / C=1.0 / B=1.2 / A=1.4 / S=1.6、担当なし0.5）× 施設 × やる気 × 疲労 × 才能 × 特徴タグ
- 授業でも経験値：毎週+5（全員）
- 目標技能が夢に沿う → 月末にやる気判定でやや上がりやすい、ずれる → やや下がりやすい

### 6.2 個人指導（平日、基本3回）
- 枠：基本週3回＋副教官1人につき+1（最大6回）。教官が50代後半以降、疲れた週は−1のことがある
- 1枠でどちらかを選ぶ：
  - **技能指導**：1人の指定技能+25（副教官の指導は+15）、才能判明度+15（副教官+8）、疲労+10、経験値+10
  - **面談**：話題は状況で自動（やる気が低い→悩み／3年生→進路／才能ヒントあり→兵種／予兆あり→引き止め）。やる気+1段階、退学予兆の解消、夢・才能のヒント、**教官への信頼+10**
- **生徒からの相談**：週に0〜2件、「先生、少しいいですか」とやること一覧に届く。受けると指導枠1つを使って面談と同じ効果（＋相談内容に応じた追加効果）、断るとやる気−1段階

### 6.3 週末の交流（1〜2回、収穫祭の月は+1回）
| 行動 | 対象 | 効果 |
|---|---|---|
| 休養 | 全員 | 疲労−25 |
| お茶会 | 生徒2〜3人を招く | 招いた子同士の支援+8、やる気+1段階、支援会話が起きやすい、疲労−5 |
| 手合わせ | 生徒2人を組ませる | 2人の支援+6、指定技能+10、疲労+10 |
| 学年の食事会 | 1学年全員 | 全員やる気+1段階（確率70%）、学年の結束イベント |

### 6.4 自動化
- 「方針だけ決めて自動で組む」：未設定のまま「次の週へ」を押すと、担任（副教官）がいればその方針、いなければ「バランス」方針で自動設定
- 自動の方針：バランス／才能を伸ばす／夢を優先／戦闘向け

## 7. 支援と信頼

### 7.1 生徒どうしの支援
- 支援値0〜150。段階：C=30、B=70、A=120
- 上がる：お茶会、手合わせ、同じ戦闘で隣接して戦う（+2/回）、同じ学年（毎月+1）
- **関係の種類**：支援Cに達した時点で、性格の組み合わせと出来事から「友情」「ライバル」のどちらかになる。支援Bに達した時点で、組み合わせによって「恋愛」へ変わることがある（恋愛は各生徒1人まで）
- **戦闘効果（FE準拠、関係の種類による差はなし）**：2マス以内の支援相手1人につき、C：命中+5・回避+5 ／ B：命中+10・回避+10・必殺+3 ／ A：命中+15・回避+15・必殺+5・ダメージ+1。最大2人分まで
- 恋愛は告白・両想いなど気持ちの描写まで。卒業後に結婚することがある（§11）

### 7.2 教官への信頼（師弟の絆、恋愛要素なし）
- 0〜100。上がる：面談、相談を受ける、個人指導（+3）、夢に沿った進路推薦
- 効果：教官の推薦する進路を受け入れやすい／退学前に必ず相談に来る／卒業後の手紙（50以上で年1回ほど）／敵として再会した時の説得／卒業生講師・後継教官を引き受けやすい／戦闘の「指示」の成功率

### 7.3 支援会話（話題×口調の組み合わせ）
- プレイ中のAI生成はしない。すべてデータから組み立てる
- **①話題**：夢／出身・家柄／特徴タグ／最近の出来事（演習でかばった、同じ敵を倒した、試験に合格、仲間の退学・戦死、故郷が戦場に、収穫祭、など）／関係の種類（友情・ライバル・恋愛）
- **②流れ**：話題ごとに2〜3パターン。「切り出し→答え→掘り下げ→締め」の3〜6往復。分岐条件（夢あり/なし、貴族/孤児、同郷/他国 など）で反応を変える
- **③口調**：10性格それぞれの言い回し。各セリフは「意味ID」を持ち、性格ごとの文面を用意する
- 差し込み：名前、国名、夢の内容、出来事の詳細
- データ形式の例（`src/data/talks/*.ts`）：
```ts
{ id: "dream_ask", topic: "dream", rank: "C",
  when: { a: { hasDream: true } },
  lines: [
    { by: "a", say: "dream_share" },       // 自分の夢を語る
    { by: "b", say: { if: { b: { hasDream: false } }, then: "no_dream", else: "dream_share" } },
    { by: "a", say: { if: { b: { hasDream: false } }, then: "encourage_search", else: "respect" } },
    { by: "b", say: "thanks_soft" }
  ] }
// 口調：phrases["dream_share"]["熱血"] = "俺は{dream}！ 絶対に叶えてみせる！" など
```
- 初期は話題15〜20種、支援C・B中心。Aは特別会話として後で充実

## 8. 戦闘

> **16夜目から「札の戦い」**（`src/core/battle/cards.ts`、画面は `src/ui/CardBattle.tsx`）。下の 8.1〜8.12 のマス目の戦いは、能力・武器・三すくみ・兵種・勝利条件の考え方として残しているが、戦場を歩くマス目はもう使わない。
> - **山札**：出撃した子の「つけている戦技と魔法・スキル」（札になるもの）・伝説の武器の札・持たせた道具、足りない子はふつうの攻撃の札（1人3〜5枚）。先生の策（出撃前に選んだもの）も札になる。策を立てる子の軍略が高いほど、策の札が早く手札に来る
> - **ターン**：毎ターン手札（はじめ5枚）を引き、**行動力**（はじめ3。出撃した人数で5まで）の分だけ出す。勝利条件ごとに4〜6ターンで決着（時間切れは、守る・逃げる戦いなら勝ち、ほかは残った敵のHPが半分以下なら敵が退いて勝ち）
> - **敵の予告**：前に出ている敵（3〜5人。倒れると控えが前に出る）は、次の行動（狙う相手と数）を見せる。敵の攻撃に会心はない（読めば守れる）。敵将は大振り・怒りの構え・得意の戦技を使う
> - **札の種類**：攻撃（回数・前の敵すべて・止める・弱める）、守り（かばう＝受ける傷半分・みんなの守り・自分の守り・反撃）、回復、強め（このターンの威力・命中、次のターンの行動力・札）、策
> - 前列・後列（近くで戦う敵は前列を狙う）、三すくみ・特効・敵将の弱点、支援、条件で効くスキル（HPが半分以下・仲間が倒れた・先に攻撃した・敵将と戦う・HPが満タン）は、札の数に入る
> - **信頼**：信頼の低い子（55未満）の札は、ときどき自分の判断で別の攻撃の札になる
> - ここぞの判断（宿命の対決・一騎打ち・説得・執着）は2ターン目・4ターン目のあと。小さな依頼と、教官が同行しない部隊は、部隊長がおまかせで札を出して結果だけ
> - 結果の文は4段（ふつう・深手・重傷・死）。死ぬ段の言葉は死のときだけ（`docs/writing-style.md` 5-5c）

### 8.1 マップ
- **縦12×横8マス**。スマホ縦画面で1マスが指で押せる大きさ（約44px以上）。縦は軽くスクロール
- **手作りの型を自動で組み替える**：型＝道と大まかな地形（固定）＋可変部分（木・岩の位置、敵の数と兵種、宝箱の位置）
- 型（初期8種）：森の街道／山の砦／国境の村／川辺の橋／丘陵の野営地／廃墟の街／訓練場（演習専用）／学校（防衛戦専用、固定）
- 生成後に「敵戦力の合計」を計算し、依頼の推奨レベルに対して範囲内に収まるまで調整
- 出撃人数：初年度6人 → 生徒数に応じて最大10人（在籍数12人以上で8人、20人以上で10人）

### 8.2 地形
| 地形 | 効果 |
|---|---|
| 平地 | なし |
| 森 | 回避+20、移動コスト2（騎兵系3） |
| 山 | 回避+30、歩兵2・飛行1のみ通行可 |
| 砦 | 守備+2・回避+20、ターン開始時HP20%回復 |
| 川 | 飛行のみ（橋は誰でも） |
| 村 | 訪問するとアイテムや情報。防衛戦では守る対象 |
| 壁 | 通行不可 |

### 8.3 天候（戦闘中は変わらない）
- 晴れ：なし／雨：銃が使えない、全員の移動−1（飛行は−0）／霧：弓・魔道・銃の射程−1（最低1）
- 依頼に天候が表示される

### 8.4 計算式（FE準拠）
- 攻撃力＝力（魔道は魔力）＋武器威力（三すくみ有利+1/不利−1）
- ダメージ＝攻撃力−守備（魔道は魔防、銃は守備の半分）、最低0
- 命中＝武器命中＋技×2＋幸運÷2（三すくみ有利+15/不利−15）＋支援
- 回避＝速さ×2＋幸運＋地形＋支援
- 実命中＝命中−回避（0〜100）。**乱数は2回の平均**（FEの表示命中より体感に近い）
- 必殺＝武器必殺＋技÷2＋支援、必殺回避＝幸運。必殺はダメージ3倍
- 追撃：速さが4以上上回ると2回攻撃
- 反撃：相手の射程内なら反撃

### 8.5 三すくみ
- 剣＞斧＞槍＞剣。弓は飛行に特効（威力×3）。魔道は相性なしで魔防で受ける。銃は三すくみの外

### 8.6 武器と道具
- **耐久なし**。ランク：鉄→鋼→銀→特殊
- 武器は**学校の武器庫**の共有物。出撃前に割り当てる（技能ランク不足は装備不可）
- 初期の武器庫：鉄の剣×3、鉄の槍×2、鉄の斧×2、鉄の弓×2、ファイアー×1、ライブ×1（回復の杖）
- 購入（月末の依頼選択画面か武器庫画面で）：鉄 300G前後、鋼 700G前後、銀 1800G前後、特殊は依頼報酬や村訪問でのみ入手
- 武器の例（威力/命中/必殺/射程/必要ランク）：鉄の剣 5/90/0/1/E、鋼の剣 8/80/0/1/D、銀の剣 12/75/0/1/B、キルソード 9/80/30/1/C、鉄の弓 6/85/0/2/E、ロングボウ 7/65/0/2-3/C、ファイアー 5/90/0/1-2/E、サンダー 7/75/5/1-2/D、トロン 11/70/10/1-2/B、ライブ（回復10）/–/–/1/信仰E、リライブ（回復20）/信仰C、など
- **魔道は武器扱い**（魔道書、耐久なし）
- **卒業時に1本だけ持っていける**：その子が最も多く使った武器。戦死の知らせとともに遺品として学校の武器庫に戻ることがある（名前と元の持ち主が刻まれる）
- 道具：傷薬（HP+10）、特効薬（HP全回復）。消耗品。出撃時に1人1つまで持たせられる

### 8.7 銃（登場後）
- 射程2〜4、威力高、**相手の守備を半分無視**
- **装填**：撃った次の自分のターンは撃てない（移動は可）
- 隣接されると反撃できない
- 雨の日は使えない
- 銃の技能は、銃の登場後に授業として追加される

### 8.9 教官の指示（教官は戦場に出ない）
- 1ターンに1回、次のどれかを出せる
  - **もう一度動け**：行動済みの1人をもう一度動かす（1戦闘1回）
  - **狙え**：1人のこのターンの命中+15
  - **下がれ**：瀕死の1人を戦場から安全に撤退させる（1戦闘1回、ロスト回避の最後の手段）
- 成功率：基本80%、対象の信頼が高いほど上がる（信頼×0.2%、最大100%）

### 8.10 スキル（自動発動のみ、戦技なし）
- 兵種の固有スキル1つ＋特徴タグ・性格によるスキル
- 戦技・計略は作らない（後から足せる作りに）

### 8.11 敵AI（FE標準）
- 攻撃対象の優先：①倒せる相手 ②ダメージを多く与えられる相手 ③回復役 ④HPの低い相手
- 部隊ごとの動き方：**突撃**（最初から向かってくる）／**待ち伏せ**（射程に入るまで動かない）／**拠点防衛**（決まった場所から動かない）
- 撤退する敵はなし
- 敵の兵種と能力は依頼の推奨レベルと戦況（年数・緊張度）に応じて生成

### 8.12 勝利条件（7種）
全滅／ボス撃破／拠点制圧／指定ターン防衛／護衛（守る対象を目的地へ）／救出（村人を連れ出す）／突破（指定マスに到達）
- 敗北条件：味方全滅、護衛・防衛対象の撃破、指定ターン超過など
- 依頼の種類ごとの向き：演習＝全滅・ボス／盗賊・魔物退治＝全滅・ボス／村の防衛＝防衛・救出／商人の護衛＝護衛／砦の攻略＝制圧／学校防衛戦＝防衛（特別）

### 8.13 戦死と重傷
- **演習は死なない**（HP0で戦闘から抜けるだけ）
- **実戦でHP0**：「戦死」か「重傷」を判定
  - 重傷になる確率＝50%＋幸運×1%＋（2マス以内の支援Bの仲間1人につき+5%、Aで+10%）＋特徴タグ、最大90%
  - 重傷：戦闘から抜け、3〜5週間の離脱（授業・指導・出撃不可）
  - 戦死：その生徒は失われる。学校の年表と卒業写真（空席）に記録
- 難易度設定（§18）で確率を調整可能

### 8.14 巻き戻し
- 1戦闘につき3回まで、数ターン前（最大5ターン）に戻れる。演出は「教官が戦況を読み直し、指揮をやり直す」
- 設定でオフにできる
- 戦闘外の手動セーブ・ロードはなし

### 8.15 経験値
- 攻撃を当てた+10、倒した+30（相手とのレベル差で増減）、回復+12、戦闘に出撃して生還+5
- 授業でも毎週+5（全員）
- 卒業時の目安：Lv20〜30（ほぼ出撃なしで15前後）

### 8.16 操作と演出
- 操作：味方をタップ→移動範囲（青）と攻撃範囲（赤）→移動先をタップ→攻撃相手をタップで**戦闘予測**（命中・威力・必殺・追撃・反撃・三すくみ）→「決定」／「戻る」
- 敵をタップでその敵の攻撃範囲。全敵の範囲を一括表示するボタン
- 演出：**数値ポップ**と**簡易カットイン**（両者の似顔絵とHPバー、約1秒）を切り替え。初期設定は「必殺・撃破・ボス戦だけカットイン」
- 敵ターンの速度3段階＋スキップ
- 剣を振るなどの戦闘アニメーションは作らない
- 戦闘後に**講評**：生徒ごとの評価（S〜C）とひとこと

## 9. 月末の戦闘（依頼掲示板）

- 毎月、**演習1つ＋実戦依頼2〜3件**から1つを選ぶ。追加出撃なし
- 演習：死なない、報酬なし、経験値×0.7、評判+0
- 実戦：報酬（学校の収入）、経験値×1.0、評判+、三国からの依頼なら友好度と戦況が動く。戦死あり
- 依頼の表示：依頼主（三国・村・商人など）／勝利条件／推奨レベル／報酬／危険度★1〜3／天候
- 依頼の内容は緊張度で変わる：平和期＝盗賊・魔物退治中心、緊張期＝国境の小競り合い・護衛、激戦期＝国境の村の防衛・避難民の護衛
- 行事の月（9月の演武会、学校防衛戦が起きた月）は特別な戦闘で選択なし
- 卒業生が戦場に現れる（§11.4）

## 10. 入学・卒業・進路

### 10.1 入学試験（4月）
- 志願者の数＝定員×（1＋評判÷40）程度。初年度は定員程度しかいないので実質全員合格
- 志願書で見えるもの：現在の能力・技能・性格・夢・出身・一部の特徴タグ（才能・成長率は見えない）
- 合格者を選ぶ（定員まで）
- 志願者の質：評判が高いほど能力と成長率の平均が上がる
- 戦況による変化：緊張期・激戦期は戦災孤児の志願者が増える
- 卒業生の子（§11.3）は優先的に志願してくる
- スカウトは作らない（後で追加候補）

### 10.2 オープニング（最初の1回）
1. 教官の名前と経歴を決める
2. 辺境の学校に着任：ボロボロの校舎、迎える老いた管理人
3. 「3年以内に立て直せなければ廃校」の宣告
4. 一期生6〜8人と対面（入学試験は実質全員合格）
5. 1ヶ月目：やること一覧に沿って吹き出しで最低限の案内。月末の演習で戦闘の操作も案内
6. 2ヶ月目以降は案内なし。設定で案内オフ可能

### 10.3 進路（3月、三者で決まる）
1. **各国からの声かけ**：演武会・実戦での活躍、兵種、魅力、その国との友好度で決まる。声がかからない国には行けない
2. **本人の希望**：夢・出身国・性格による「行きたい国」の順位
3. **教官の推薦**：1つ勧められる。信頼が高いほど受け入れる（受け入れ確率＝30%＋信頼×0.6%）
- 推薦と希望が一致→やる気満々で巣立つ（卒業後の成長+10%）
- 推薦を押し切った→少し不満（卒業後の成長−10%）
- **進路の種類**：三国の軍／学校に残る（講師見習い→講師→副教官）／故郷に帰る（戦争から離れる、たまに手紙）／流れの傭兵（どの国にも属さない、敵として現れることも）
- **道（武官・参謀・文官）**は卒業時の能力と兵種で向いているものが自動で決まり、推薦で別の道を勧めることもできる

### 10.4 卒業式
- 卒業生が一人ずつ登場し、進路と教官への一言
- 一言は、夢が叶ったか・推薦と希望の一致・信頼・才能と夢のどちらを選んだか、で変わる。信頼が低いと一言なしで去る
- 例：「騎士になれました。先生のおかげです」／「弓を選んで、よかったと思っています」／「……帝国に行きたかったです。でも、行ってきます」
- **卒業写真**：その学年の全員の似顔絵が並んだ1枚を年鑑に保存。退学した子・在学中に戦死した子は**空席**として残る

## 11. 卒業生

### 11.1 3つの道と役職
| 道 | 出世の条件 | 役職（役職ポイント） | 戦争への影響 |
|---|---|---|---|
| 武官 | 戦闘力・レベル | 兵士(1)→小隊長(2)→部隊長(4)→将軍(8)→元帥(15) | 所属国の国力を押し上げる |
| 参謀 | 技・魔力・指揮の実績 | 参謀見習い(1)→作戦参謀(3)→参謀長(6)→軍師(12) | 所属国の戦闘の勝率（国力の変動）を上げる |
| 文官 | 魅力・信頼・出身 | 書記官(1)→外交官(3)→大使(6)→宰相(12) | 国どうしの関係を良くする、和平の可能性 |
- 役職名に兵種を添えて表示（例：部隊長（パラディン））

### 11.2 毎年のシミュレーション（年度末）
卒業生一人ずつ：
- 経験値（役職と配属先で変化）→ レベルアップ（最大50）→ 最上級兵種への昇進（上級でLv30以上など）、国専用兵種の判定
- 昇進：レベル・能力・役職年数・所属国の待遇（王国は家柄、帝国は実力、同盟は魅力）で判定
- 出来事（確率は緊張度と配属で変わる）：負傷、**戦死**（武官・前線ほど高い。平和期1%、緊張期3%、激戦期7%、帝国の前線+3%）、転属、**寝返り**（信頼が低く所属国と不仲、まれ）、引退（48〜55歳）、**結婚**（支援Aの恋愛相手が生存し同じ国か近い配属なら年15%）、**子の誕生**
- 引退した卒業生は年鑑の「歴代卒業生」に残る
- 信頼50以上の卒業生から年1回ほど**手紙**（郵便受け、§16.5）

### 11.3 卒業生の子の入学
- 結婚した卒業生どうしの子は、約20年後（18〜20歳になる年）に優先して志願してくる
- 親の髪色・成長率の一部・才能を受け継ぐ。敵国どうしの両親なら「両方の国の血」
- 個人ページに「父：○○（一期生）」と表示。年鑑の家系に記録

### 11.4 戦場に現れる卒業生（年1〜3回、緊張度が高いほど増える）
- **援軍**：依頼主の国に配属された卒業生が途中参戦。その戦闘中はプレイヤーが操作できる（戦死あり）
- **敵**：相手国の部隊長として登場。隣接して「説得」→信頼が高ければ戦闘から退く（60以上）か寝返る（80以上で一定確率）。低ければ戦うしかない
- 倒すと戦死か重傷（§8.13と同じ判定）。年鑑に記録

### 11.5 個人ページ
- 現在の役職・兵種・レベル・能力・所属国・道・経歴（年ごとの出来事）・届いた手紙・在学中の思い出（支援相手、講評のベスト、卒業式の一言）・家族

## 12. 戦況

### 12.1 3つの数値
- **国力**（各国 0〜100）：開始時 王国55・帝国65・同盟50
- **国どうしの関係**（3組、−100〜+100）：段階＝戦争（−50未満）／緊張（−50〜0）／友好（0〜50）／同盟（50超）。開始時 王国⇔帝国 −30、帝国⇔同盟 −10、同盟⇔王国 +10
- **大陸の緊張度**（0〜100）：平和期（35未満）／緊張期（35〜65）／激戦期（65超）。開始時30
- **学校⇔各国の友好度**（各 −50〜+100、開始時は経歴による）

### 12.2 動く時期
- **毎月（小さく）**：実戦依頼の結果（例：王国の村を守った→王国の国力+1、学校⇔王国の友好度+3）
- **年度末（大きく）**：
  - 国力：所属武官の役職ポイント合計×0.3＋参謀の役職ポイント×（勝率補正）＋ランダム（±3）＋大事件の影響
  - 関係：文官の役職ポイントが両国にいるほど改善（両国の文官ポイントの小さい方×0.5）、戦争中の国どうしは自然に悪化（−3）
  - 緊張度：戦争状態の組の数×+8、友好以上の組×−5、平均国力差で増減
- 大事件（§12.4）は条件を満たした月に起きる

### 12.3 学校⇔各国の友好度
- 上がる：その国の依頼を受ける（+3）、その国に卒業生を送る（+5/人）、その国出身の生徒の入学（+1/人）
- 下がる：敵対する国（関係が「戦争」の相手国）への肩入れ（その国の依頼・派遣で−2）、その国の卒業生を戦場で倒す（−10）
- 高い：援助金↑、演武会での声かけ↑、推薦が通りやすい
- 低い（−20以下）：声かけ↓、援助停止、圧力イベント（「敵国への派遣をやめよ」）
- 極端に偏る（ある国が他の2国より50以上高い）：その国から「傘下に入らないか」と誘い

### 12.4 大事件（初期10本、すべて手書きイベント＋卒業生の配置で分岐）
| 大事件 | 条件 | 回数 | 起きると |
|---|---|---|---|
| 銃の登場 | 3〜6年目のどこか | 一度 | 帝国が銃を得る。銃の授業・兵種・射撃場が解放 |
| 国境紛争 | ある2国の関係が「緊張」の下半分 | 繰り返し | 関係−15、国境の依頼が増える |
| 帝国の侵攻 | 帝国の国力70以上かつ王国と「戦争」 | 繰り返し | 王国の国力−10、王国所属の卒業生の戦死率↑、手紙「教え子が最前線にいる」 |
| 王の崩御 | 5年目以降のどこか | 一度 | 王国で後継争い。側近（王国の文官・参謀上位）に教え子がいれば王国の方針（帝国との関係）が変わる |
| 同盟の内紛 | 同盟の国力40以下 | 繰り返し | 同盟の国力−8。同盟の文官の教え子が大使以上なら被害を抑え、関係が改善 |
| 大飢饉 | 激戦期が2年以上続く | 繰り返し | 孤児の志願者増、援助金−30% |
| 疫病 | ランダム（年2%） | 繰り返し | その年は体調不良が起きやすい（疲労上限80） |
| 英雄の出現 | 卒業生か流れ者が大きな戦果 | 繰り返し | その国の国力+15。教え子なら年鑑に大きく記録 |
| 学校防衛戦 | 激戦期で、学校に近い国境が戦場に（確率） | 繰り返し | その月の月末は学校防衛戦（特別マップ、指定ターン防衛） |
| 和平会議 | 三国の関係がすべて0以上 | 繰り返し | 停戦交渉。三国それぞれに大使以上の文官の教え子がいれば和平エンドへ、足りなければ関係が少し改善して終わる |

### 12.5 小さな出来事（年1〜2回）
豊作（予算+）、名工の来訪（武器が安い）、他校との交流戦（特別な演習）、旅の学者の講義（才能判明度+）、など。後から数を増やす。

## 14. 教官の加齢・代替わり

### 14.1 加齢
- 毎年1歳。開始年齢は経歴で28〜35歳
- 「経験」：教えた生徒の延べ人数で増え、才能判明度の上がり方+（経験÷20）
- 50代後半：疲れた週は指導枠−1のことがある（週20%）

### 14.2 引退と後継
- 50歳以降、年度末にいつでも引退を選べる。65歳で必ず引退
- 後継の候補：**卒業生なら誰でも**
  - 講師・副教官：すぐ引き受ける
  - 各国の卒業生：信頼が高いほど引き受けやすい（断られることもある）
  - 将軍・宰相などを呼び戻すと、その国の国力・関係から重要人物が抜ける
  - 候補がいなければ外部の教官（「流れの旅人」相当）
- 引き継ぐもの：学校・生徒・予算・年鑑。新教官の得意授業と三国との縁は、本人の兵種・道・所属していた国で決まる
- 二代目以降も同じように続く

### 14.3 副教官（学年の担任）
- 学校に残った卒業生（講師見習い→講師→副教官、各1年以上）
- 1人が1学年を担当（最大3学年）
- 方針（バランス／才能を伸ばす／夢を優先／戦闘向け）に従い、担当学年の目標技能と週末の過ごし方を自動で組む。担任自身の得意技能と性格で解釈が少し変わる
- 副教官1人につき個人指導枠+1（伸びは教官より小さい）
- 教官はいつでも上書きできる。戦闘の指揮は任せない

4. エンドロール：歴代の卒業写真が一期ずつ、全卒業生の名前（戦死者には小さな印）。読み飛ばしボタン、名前は速めに
5. 最後の一枚（和平なら三国の代表として並ぶ教え子の写真）

### 15.3 エンディング後
- 「この学校を続ける」：平和な時代（戦争の大事件なし、依頼は魔物退治・治安維持、まれに再び戦争）

## 16. 画面

### 16.1 デザイン
- 土台：企画書の「明るい学び舎」＝クリーム色の紙・深緑・朱色、手帳のような雰囲気
- **緊張度で色合いが変わる**（CSS変数を3組用意して切り替え）
  - 平和期：クリーム `#f6f1e6`、深緑 `#2f6b5a`、朱 `#b4432f`
  - 緊張期：黄ばんだ紙 `#ece0c8`、くすんだ緑、茶、夕暮れの色調
  - 激戦期：灰色がかった紙 `#cfcbc4`、深い紺 `#1f2a40`、暗い赤 `#7a2a2a`、夜の色調
- フォント：見出しは明朝系（Noto Serif JP など）、本文はゴシック系。外部フォント読み込みは任意（なくても崩れないこと）
- 縦画面基準、横幅360〜430pxで崩れないこと。PCでは最大幅を決めて中央寄せ、広ければ2列

### 16.2 基本構成：下に5つのタブ＋「次の週へ」
1. **学校**（ホーム）：今週の状況（年・月・週、所持金、評判、緊張度）、**やること一覧**、気にかける生徒、今月の主役、「次の週へ」ボタン
2. **生徒**：学年ごとの名簿（並べ替え・絞り込み）、個人ページ、目標技能の設定、兵種試験
3. **戦況**：三国の国力・関係・緊張度、学校との友好度、簡易地図（三国の位置と関係の線の色）、依頼掲示板
4. **年鑑**：卒業生名簿、卒業写真、年表、記録、殿堂
5. **設定**：セーブ枠、書き出し・読み込み、難易度と細かな調整、表示（似顔絵/色の丸、演出、敵ターン速度）、巻き戻しのオンオフ、案内のオンオフ、音

### 16.3 やること一覧
- 例：「個人指導 あと2回」「週末の交流 未設定」「兵種試験を受けられる生徒が2人」「相談：リオ」「才能のヒント：ミア」
- 押すと該当画面へ。全部済ませなくても「次の週へ」で進める（未設定分は自動）

### 16.4 その他の画面
- 週のまとめ（成長・変化の一覧、才能のヒント）
- 戦闘画面、戦闘予測、講評
- 入学試験、卒業式、卒業写真
- 兵種試験（合格率表示）
- 施設・講師・武器庫
- 年度末の新聞
- オープニング、エンディング

### 16.5 新聞と郵便受け
- **新聞**（年度末と大事件の月）：一面に大事件・戦況、下に「卒業生の消息」欄（昇進・兵種昇格・結婚・戦死・英雄など大きなものだけ）。名前から個人ページへ。激戦期は紙面も暗く
- **郵便受け**（随時）：卒業生からの手紙、在校生の家族の便り、三国の依頼状・圧力の書簡。ホームのタブに未読数
- 手紙の例：「先生、お元気ですか。王国の騎士団で小隊長になりました。北は寒いです。後輩たちにもよろしく。—リオ（一期生）」

### 16.6 音
- 効果音のみ（Web Audioで合成）：決定・取り消し、移動、命中・外れ、必殺、撃破、レベルアップ、兵種試験合格、卒業式、訃報（静かな音）
- BGMは後から音源ファイルを置けば流れる枠を用意（`public/bgm/peace.mp3`, `tension.mp3`, `war.mp3`, `battle.mp3` があれば再生）
- 音量・効果音オンオフは設定で。iPhoneは最初のタップ後に音声を有効化すること

## 17. セーブ

- ブラウザ内に自動保存（IndexedDB推奨、使えなければlocalStorage）。毎週の終わり＋戦闘中は毎ターン
- **書き出し・読み込み**：セーブデータをJSONファイルで書き出し／読み込み（PC⇔スマホ移行・保険）
- セーブ枠3つ。殿堂は枠とは別に保存
- iPhone対策：PWA（ホーム画面に追加）で使う前提。初回起動時に「ホーム画面に追加」を案内。「最後の書き出しから14日」を過ぎたらお知らせ
- セーブデータにはバージョン番号を持たせ、将来の形式変更に備える（読み込み時に変換）

## 18. 難易度

- やさしい／ふつう／むずかしい の3段階＋**細かな調整（いつでも変更可）**

- 「ふつう」をこの設計書の数値とする

## 19. 技術（実装の方針）

- **TypeScript＋Vite**。静的サイトとしてビルドし、**GitHub Pages**で公開（GitHub Actionsで自動公開）
- 画面フレームワークは任意（Preact か 素のTS＋軽量な仕組みを推奨。重いものは避ける）
- **ゲームの計算（ロジック）と画面を分ける**：`src/core/`（純粋な計算・状態・乱数・シミュレーション、DOMに依存しない）と `src/ui/`
- **乱数はシード付き**（再現性のため。テストと巻き戻しに必要）
- **データは `src/data/` に集約**：兵種、武器、名前、性格、夢、特徴タグ、才能、会話、マップの型、イベント、バランス値
- **自動テスト**（Vitest）：計算式、成長、兵種試験、戦闘、セーブの読み書き
- **長期シミュレーション**（画面なし、`npm run sim`）：オートプレイで数十年回し、戦争が5〜40年で終わるか、お金が破綻しないか、評判・人数が想定どおり増えるか、を確認して `docs/sim-report.md` に書き出す
- PWA：manifest とサービスワーカー（オフラインで遊べる）。Viteのbaseはリポジトリ名（`/rimina-academy/`）

## 20. 開発の進め方（3回に分ける）

各回の終わりにヒナタさんが遊び、感想をもとに次へ。段階ごとに自動テスト→コミット。詰まった機能は後回しにして報告に「未完成」として残す。

- **1夜目**：①土台 ②1週間 ③戦闘 ④1年 ⑤年またぎ ⑥戦況の基本（詳細は `docs/night1.md`）
- **2夜目**：1夜目の修正＋⑦全兵種（上級・最上級・国専用）と全大事件・小さな出来事＋⑧支援会話の拡充・手紙
- **3夜目**：2夜目の修正＋⑨教官の加齢・代替わり・副教官・エンディング・殿堂・仕上げ
