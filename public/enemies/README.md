# 敵将の顔画像

敵将（名前と性格を持つ指揮官・頭目）の「胸から上」の顔画像。生徒の顔（`public/faces/`）と同じ画風。

- ファイル名：`{陣営}_{性別}_{年代}_{番号}.webp`
  - 陣営：kingdom（王国軍：白と紺の鎧・八角の星）／empire（帝国軍：赤と黒・太陽）／alliance（同盟軍：緑と白・花）／bandit（盗賊団）
  - 性別：m / f
  - 年代：young（20代）／middle（30〜40代）／old（50代以上）
- 追加したら `index.json` の `files` に書き足す
- 魔物の群れの頭には使わない（兵種のアイコンか似顔絵のまま）
- 「傷を負って戻った」敵将は、同じ画像の上に傷跡・包帯・眼帯をゲーム側で重ねて表す
- 卒業生が敵として現れるときは、生徒のときの顔（`public/faces/`）のまま
